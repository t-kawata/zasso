# RFC_001: CLI レイヤ（conver-cli）

## Abstract

本RFCは、`conver` オーケストレータのCLIレイヤ `conver-cli` crate の設計を規定する。
`conver-cli` は clap によるコマンドライン引数パース、5層設定解決、ドメイン
ハンドラへの WorkflowRequest ルーティング、埋め込みアセットの初期配布（init）、
およびレガシースクリプト互換レイヤ（conver cmd）の責務を負う。

親RFC: [RFC_ROOT.md](crates/conver/RFC_ROOT.md)（conver: 決定論的 Rust オーケストレータ）
crate 実装先: `crates/conver/rfc-001-cli/`
結合先: `crates/conver/src/` において全サブcrateと統合され、
`crates/conver` として単一バイナリを構成する。

```text
crates/
  conver-cli/       ← 本RFCの実装範囲
  conver-core/      # RFC_002
  conver-runtime/   # RFC_003
  conver-storage/   # RFC_004
  conver-projection/# RFC_005
  conver-validation/# RFC_005
  conver-compat/    # RFC_001（本RFCの一部として実装）
```

## Motivation

`conver` の全機能へのアクセスはCLIインターフェースを経由する。CLIレイヤは以下を
提供しなければならない：

1. **機械的決定論性**: 同一引数からは同一の WorkflowRequest が生成される。
   Claude Code の非決定論はこの層より下位（Runtime adapter）で隔離される。
2. **発見可能性**: 全サブコマンドとフラグは `--help` で完全に文書化される。
3. **設定透過性**: デフォルト値・グローバル設定・プロジェクト設定・`-f` 設定・
   CLIフラグの5層を透過的にマージする。
4. **後方互換性**: 既存の `node .claude/scripts/...` 呼び出しは `conver cmd ...`
   互換レイヤを通じて同一動作を提供する。
5. **1回完結**: 全コマンド・全設定はphase分割なしで本RFCの実装範囲内で完結する。

```bash
# 目標とするCLI体験
conver init --into /path/to/project
conver rfc grill --research ./research --output ./rfc/conver.md
conver rfc status
conver rfc checklist generate
conver ticket create --title "..." --rfc-node rfc-002
conver ticket list --status pending
conver quality run
conver malfeasance scan
conver cmd grill-me-for-rfc ./research ./rfc/conver.md  # 互換
```

## Design

### 1. システム構造

`conver-cli` は以下の層で構成される。

```text
[エントリポイント] main.rs
    │
    ├── [パース層] parser.rs
    │    clap Command enum → Settings + WorkflowRequest
    │
    ├── [設定解決層] config.rs
    │    5層マージ: defaults < global < project < -f < flags
    │
    ├── [ルーティング層] router.rs
    │    WorkflowRequest → conver-core::controller::execute()
    │
    ├── [init層] init.rs
    │    埋め込みアセット展開 + マニフェスト書出
    │
    └── [互換層] compat.rs
        レガシースクリプト引数 → canonical WorkflowRequest
```

各層は一方向の依存関係を持ち、下位層は上位層を参照しない。

```rust
// conver-cli/src/lib.rs

pub mod config;
pub mod router;
pub mod init;
pub mod compat;
```

### 3. 設定解決

5層の設定マージは以下に従う：

```rust
// conver-cli/src/config.rs
use std::path::PathBuf;

pub struct ConfigResolver;

impl ConfigResolver {
    /// 5層マージを実行し、解決済み Settings を返す。
    /// 優先順位: defaults < global < project < -f < CLI flags
    pub fn resolve(cli_settings: Settings) -> Result<Settings, ConfigError> {
        let mut settings = Settings::defaults();             // 層1: ビルトインデフォルト
        settings.merge(&Self::load_global()?)?;              // 層2: グローバル設定
        settings.merge(&Self::load_project()?)?;             // 層3: プロジェクト設定
        if let Some(f) = &cli_settings.paths.config_file {
            settings.merge(&Self::load_file(f)?)?;           // 層4: -f 指定ファイル
        }
        settings.merge(&cli_settings);                       // 層5: CLIフラグ（最優先）
        Ok(settings)
    }

    fn load_global() -> Result<Settings, ConfigError> {
        let path = dirs::config_dir()
            .map(|p| p.join("conver/settings.json"))
            .ok_or(ConfigError::NoHomeDir)?;
        Self::load_file(&path).or_else(|_| Ok(Settings::defaults()))
    }

    fn load_project() -> Result<Settings, ConfigError> {
        // カレントディレクトリから遡って .conver/settings.json を探索
        let cwd = std::env::current_dir()?;
        for ancestor in cwd.ancestors() {
            let path = ancestor.join(".conver/settings.json");
            if path.exists() {
                return Self::load_file(&path);
            }
        }
        Ok(Settings::defaults())
    }

    fn load_file(path: &PathBuf) -> Result<Settings, ConfigError> {
        let content = std::fs::read_to_string(path)
            .map_err(|e| ConfigError::Io(path.clone(), e))?;
        let settings: Settings = serde_json::from_str(&content)
            .map_err(|e| ConfigError::Parse(path.clone(), e))?;
        Ok(settings)
    }
}

pub trait Merge {
    fn merge(&mut self, other: &Self) -> Result<(), ConfigError>;
}

impl Merge for Settings {
    fn merge(&mut self, other: &Self) -> Result<(), ConfigError> {
        // Some(T) のフィールドのみ上書き、None は無視
        if other.runtime.backend != "claude-code" {
            self.runtime.backend.clone_from(&other.runtime.backend);
        }
        // ... 全フィールド同様のパターン
        Ok(())
    }
}
```

### 4. ルーティング

パース済みの Command を WorkflowRequest に変換し、conver-core の
WorkflowController へ渡す。

```rust
// conver-cli/src/router.rs
use conver_core::controller::{WorkflowController, WorkflowRequest};
use crate::parser::Command;

pub fn route(
    command: Command,
    controller: &mut dyn WorkflowController,
    settings: Settings,
) -> Result<(), RoutingError> {
    let request = match command {
        Command::Init(args) => WorkflowRequest::Init(InitRequest {
            target_path: args.into,
            manifest: settings.install,
        }),
        Command::Rfc(RfcCommand::Grill { research, output, .. }) => {
            WorkflowRequest::GrillRfc(GrillRfcRequest {
                research_path: research,
                output_path: output,
            })
        }
        Command::Rfc(RfcCommand::Status { rfc_dir }) => {
            WorkflowRequest::ShowStatus(StatusRequest { rfc_dir })
        }
        Command::Rfc(RfcCommand::ChecklistGenerate { rfc_dir }) => {
            WorkflowRequest::GenerateChecklist(ChecklistRequest { rfc_dir })
        }
        Command::Rfc(RfcCommand::TreeSplit { rfc }) => {
            WorkflowRequest::SplitRfcTree(TreeSplitRequest { rfc_path: rfc })
        }
        Command::Rfc(RfcCommand::Omissions { rfc }) => {
            WorkflowRequest::DetectOmissions(OmissionsRequest { rfc_path: rfc })
        }
        Command::Ticket(TicketCommand::Create { title, rfc_node, depends_on }) => {
            WorkflowRequest::CreateTicket(CreateTicketRequest {
                title, rfc_node_id: rfc_node, depends_on,
            })
        }
        Command::Ticket(TicketCommand::Plan { ticket_id }) => {
            WorkflowRequest::PlanTicket(ticket_id)
        }
        Command::Ticket(TicketCommand::Start { ticket_id }) => {
            WorkflowRequest::StartTicket(ticket_id)
        }
        Command::Ticket(TicketCommand::Review { ticket_id }) => {
            WorkflowRequest::ReviewTicket(ticket_id)
        }
        Command::Ticket(TicketCommand::Resolve { ticket_id }) => {
            WorkflowRequest::ResolveTicket(ticket_id)
        }
        Command::Ticket(TicketCommand::List { status, rfc_node }) => {
            WorkflowRequest::ListTickets(ListTicketsRequest { status, rfc_node_id: rfc_node })
        }
        Command::Ticket(TicketCommand::Formulate { rfc_node }) => {
            WorkflowRequest::FormulateTickets(FormulateRequest { rfc_node_path: rfc_node })
        }
        Command::Malfeasance(MalfeasanceCommand::Create { description, rfc_node, ticket }) => {
            WorkflowRequest::CreateMalfeasance(MalfeasanceCreateRequest {
                description, rfc_node_id: rfc_node, ticket_id: ticket,
            })
        }
        Command::Malfeasance(MalfeasanceCommand::Resolve { malfeasance_id }) => {
            WorkflowRequest::ResolveMalfeasance(malfeasance_id)
        }
        Command::Malfeasance(MalfeasanceCommand::List { status }) => {
            WorkflowRequest::ListMalfeasance(status)
        }
        Command::Malfeasance(MalfeasanceCommand::Scan) => {
            WorkflowRequest::ScanMalfeasance
        }
        Command::Quality(QualityCommand::Run { gate }) => {
            WorkflowRequest::RunQualityChecks(QualityRequest { gate })
        }
        Command::Runtime(RuntimeCommand::Start { request }) => {
            WorkflowRequest::RuntimeStart(request)
        }
        Command::Runtime(RuntimeCommand::Stop { run_id }) => {
            WorkflowRequest::RuntimeStop(run_id)
        }
        Command::Runtime(RuntimeCommand::Status { run_id }) => {
            WorkflowRequest::RuntimeStatus(run_id)
        }
        Command::Cmd(compat) => {
            // 互換レイヤが WorkflowRequest に変換する
            crate::compat::translate(compat)?
        }
    };
    controller.execute(request)
        .map_err(RoutingError::ExecutionFailed)?;
    Ok(())
}
```

### 6. Init コマンド

埋め込みアセットをファイルシステムに展開する。

```rust
// conver-cli/src/init.rs
use conver_core::manifest::{ManifestAsset, Manifest};
use crate::EmbeddedAsset;

pub struct InitRunner;

impl InitRunner {
    pub fn run(target_path: &Path, conflict_policy: &ConflictPolicy) -> Result<Manifest, InitError> {
        let mut manifest = Manifest::new();

        for asset in Self::embedded_assets() {
            let target = target_path.join(&asset.relative_path);
            if target.exists() {
                match conflict_policy {
                    ConflictPolicy::PreserveAndSuffix => {
                        let backup = target.with_extension("bak");
                        std::fs::rename(&target, &backup)?;
                    }
                    ConflictPolicy::OverwriteIfForced => { /* 上書き */ }
                    ConflictPolicy::RejectAndReport => {
                        return Err(InitError::Conflict(asset.logical_name));
                    }
                }
            }
            if let Some(parent) = target.parent() {
                std::fs::create_dir_all(parent)?;
            }
            std::fs::write(&target, asset.bytes)?;

            manifest.assets.push(ManifestAsset {
                logical_name: asset.logical_name,
                relative_path: asset.relative_path.clone(),
                sha256: asset.sha256.clone(),
                asset_kind: asset.asset_kind.clone(),
                version: env!("CARGO_PKG_VERSION").to_string(),
                compatible_runtimes: vec!["claude-code".to_string()],
                dependencies: vec![],
            });
        }

        // マニフェスト書き出し
        let manifest_path = target_path.join(".claude/manifest.json");
        std::fs::create_dir_all(manifest_path.parent().unwrap())?;
        std::fs::write(&manifest_path, serde_json::to_string_pretty(&manifest)?)?;

        Ok(manifest)
    }

    fn embedded_assets() -> Vec<EmbeddedAsset> {
        vec![
            EmbeddedAsset {
                logical_name: "grill-me-for-rfc".into(),
                relative_path: ".claude/commands/grill-me-for-rfc.md".into(),
                bytes: include_bytes!("../../assets/commands/grill-me-for-rfc.md"),
                sha256: sha256_of(include_bytes!("../../assets/commands/grill-me-for-rfc.md")),
                asset_kind: AssetKind::SlashCommand,
            },
            // ... 全9スラッシュコマンド同様
        ]
    }
}
```

### 8. エントリポイント

```rust
// conver-cli/src/main.rs
fn main() -> ExitCode {
    use clap::Parser;
    use conver_core::controller::WorkflowControllerImpl;
    use conver_storage::file::FileBackend;

    // 1. CLI パース
    let cli = Cli::parse();

    // 2. 設定解決（5層マージ）
    let cli_settings = Settings::from_cli(&cli);
    let settings = ConfigResolver::resolve(cli_settings)
        .unwrap_or_else(|e| {
            eprintln!("設定エラー: {e}");
            std::process::exit(1);
        });

    // 3. コントローラ初期化
    let backend = FileBackend::new(&settings.paths.workspace_root);
    let mut controller = WorkflowControllerImpl::new(backend, settings);

    // 4. Init コマンドは特別処理
    if let Command::Init(args) = &cli.command {
        return match InitRunner::run(&args.into, &controller.settings.install.conflict_policy) {
            Ok(manifest) => {
                println!("{}個のアセットを展開しました", manifest.assets.len());
                ExitCode::SUCCESS
            }
            Err(e) => {
                eprintln!("初期化エラー: {e}");
                ExitCode::FAILURE
            }
        };
    }

    // 5. ルーティングと実行
    match route(cli.command, &mut controller, settings) {
        Ok(()) => ExitCode::SUCCESS,
        Err(e) => {
            eprintln!("エラー: {e}");
            ExitCode::FAILURE
        }
    }
}
```

```rust
pub struct EmbeddedAsset {
    pub logical_name: String,
    pub relative_path: PathBuf,
    pub bytes: &'static [u8],
    pub sha256: String,
    pub asset_kind: AssetKind,
```
