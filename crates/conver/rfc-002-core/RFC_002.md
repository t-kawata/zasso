# RFC_002: コア状態機械（conver-core）

## Abstract

本RFCは、`conver` オーケストレータのコアロジック `conver-core` crate の設計を
規定する。`conver-core` はワークフロー状態機械、チケット局所状態機械、
DesignTree ガバナンス、チケット CRUD と DAG 編成、Malfeasance ledger、
乖離関数Δの計算、観測ベクトル管理、収束ループ制御、RFCツリーDAG管理の
10モジュールから構成される。

本crateは全crateの中で唯一、ワークフローの「意味」を理解する層である。
CLIパース（conver-cli）、Runtime実行（conver-runtime）、永続化（conver-storage）、
プロジェクション（conver-projection）、検証（conver-validation）はいずれも
本crateの状態と判断に依存する。本crate自身は「何をすべきか」を判断するが、
「どう実行するか」「どう保存するか」は各crateに委譲する（依存性逆転）。

親RFC: [RFC_ROOT.md](crates/conver/RFC_ROOT.md)（conver: 決定論的 Rust オーケストレータ）
crate 実装先: `crates/conver/rfc-002-core/`
結合先: `crates/conver/src/` において全サブcrateと統合される。

```text
crates/
  conver-cli/       # RFC_001 — 本crateを呼び出す
  conver-core/      ← 本RFCの実装範囲
  conver-runtime/   # RFC_003 — RuntimeBackend trait の実装
  conver-storage/   # RFC_004 — StorageBackend trait の実装
  conver-projection/# RFC_005 — 本crateの状態からartifactを生成
  conver-validation/# RFC_005 — 本crateのゲートを検証
```

## Motivation

`conver-core` は以下の責務を負う唯一のcrateである：

1. **ワークフロー状態の一元管理**: `GRILLING` → `CHECKLIST_PENDING` → `CHECKLIST_APPROVED` →
   `WRITING` → `REVIEWING` → `DONE` の遷移と第一層ループ回数管理。
2. **チケットライフサイクル**: `CREATED` → ... → `DONE` の14状態遷移（補助遷移含む）。
3. **DesignTree ガバナンス**: Grillセッションの設計判断ツリー管理（add / resolve / count_open）。
4. **チケットDAG編成**: 2段階フロー（Claude Code骨格出力→DAG検証→トポロジカルソート→詳細書込）。
5. **Malfeasance ledger**: `[::STUB::]` マーカーの系統的管理（create / resolve / list / scan）。
6. **乖離関数Δ計算**: 4分類（M/C/U/X）のomissionsから乖離スコアを計算（α=2,β=2,γ=1,δ=1）。
7. **観測ベクトル管理**: ループごとの収束状態を11フィールドで記録。
8. **収束ループ制御**: Δ>0時のフィードバック先決定（種類別）とループ上限（デフォルト3）。
9. **RFCツリーDAG管理**: petgraphによるRFC_TREE.jsonのDAG検証とクエリ。

### 2. ワークフロー状態機械

#### 2.1 大域状態機械

`WorkflowState` は6状態でPhase 0–7の全行程をカバーする。Phase 0は人間専用フェーズ
でありconverの制御外であるため状態に含めない。

```rust
// conver-core/src/state.rs
use serde::{Deserialize, Serialize};

/// 大域状態機械。
///
/// Phase対応:
///   Grilling           → Phase 1 (頂点RFC策定)
///   ChecklistPending   → Phase 1→2 遷移待ち
///   ChecklistApproved  → Phase 2–3 (RFCツリー分解・チケット分解)
///   Writing            → Phase 4 (RFC執筆 / 実装)
///   Reviewing          → Phase 5–6 (乖離検出・負債管理)
///   Done               → Δ = 0 達成
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum WorkflowState {
    Grilling,
    ChecklistPending,
    ChecklistApproved,
    Writing,
    Reviewing,
    Done,
}

impl WorkflowState {
    /// 現在の状態から許可される遷移先一覧。
    pub fn allowed_transitions(&self) -> &[WorkflowState] {
        match self {
            WorkflowState::Grilling => &[WorkflowState::ChecklistPending],
            WorkflowState::ChecklistPending => &[WorkflowState::ChecklistApproved],
            WorkflowState::ChecklistApproved => &[
                WorkflowState::Writing,
                WorkflowState::Grilling,        // フィードバック（Δ>0, U → Phase 1）
                WorkflowState::ChecklistPending, // フィードバック（Δ>0, X → Phase 2）
            ],
            WorkflowState::Writing => &[WorkflowState::Reviewing],
            WorkflowState::Reviewing => &[
                WorkflowState::Done,
                WorkflowState::Grilling,
                WorkflowState::ChecklistPending,
                WorkflowState::ChecklistApproved,
            ],
            WorkflowState::Done => &[],
        }
    }

    /// 遷移を実行する。許可されていない遷移は Err を返す。
    pub fn transition(&mut self, target: WorkflowState) -> Result<(), StateError> {
        if self.allowed_transitions().contains(&target) {
            *self = target;
            Ok(())
        } else {
            Err(StateError::InvalidTransition(format!(
                "{:?} → {:?}",
                self, target
            )))
        }
    }

    /// 人間による明示的な遷移オーバーライド。
    /// 収束ループ制御からのフィードバック遷移に使用される。
    pub fn force_transition(&mut self, target: WorkflowState) {
        *self = target;
    }
}

#[derive(Debug, thiserror::Error)]
pub enum StateError {
    #[error("不正な状態遷移: {0}")]
    InvalidTransition(String),
}
```

#### 2.2 第一層ループ管理

収束ループの反復管理。最大ループ回数は `settings.report.convergence_loop_limit`
から設定される。

```rust
/// 第一層ループの各反復を記録する。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RoundRecord {
    pub round_number: u32,
    pub state: WorkflowState,
    pub entered_at: chrono::DateTime<chrono::Utc>,
}

/// ループ管理。
pub struct RoundManager {
    current_round: u32,
    max_rounds: u32,
}

impl RoundManager {
    pub fn new(max_rounds: u32) -> Self {
        Self {
            current_round: 0,
            max_rounds,
        }
    }

    /// 次のループ反復を開始する。
    /// 上限（デフォルト3）を超えている場合は Err を返す。
    pub fn start_next_round(&mut self) -> Result<u32, ConvergenceError> {
        if self.current_round >= self.max_rounds {
            return Err(ConvergenceError::LoopLimitExceeded {
                current: self.current_round,
                max: self.max_rounds,
            });
        }
        self.current_round += 1;
        Ok(self.current_round)
    }

    pub fn current_round(&self) -> u32 {
        self.current_round
    }

    /// 現在のループ番号を返す（テスト・表示用）。
    pub fn reset(&mut self) {
        self.current_round = 0;
    }
}
```

#### 2.3 チケット局所状態機械

チケットは10のメイン状態と4の補助状態を持つ。

```rust
/// チケットライフサイクル。
///
/// メイン系列:
///   CREATED → MAKING → MADE → PLANNING → PLANNED
///          → STARTING → STARTED → REVIEWING → REVIEWED → DONE
///
/// 補助系列:
///   → BLOCKED → RETRYING → ROLLED_BACK → ABORTED
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum TicketStatus {
    Created,
    Making,
    Made,
    Planning,
    Planned,
    Starting,
    Started,
    Reviewing,
    Reviewed,
    Done,
    Blocked,
    Retrying,
    RolledBack,
    Aborted,
}

impl TicketStatus {
    pub fn allowed_transitions(&self) -> &[TicketStatus] {
        match self {
            TicketStatus::Created  => &[TicketStatus::Making],
            TicketStatus::Making   => &[TicketStatus::Made, TicketStatus::Blocked, TicketStatus::Aborted],
            TicketStatus::Made     => &[TicketStatus::Planning, TicketStatus::Blocked],
            TicketStatus::Planning => &[TicketStatus::Planned, TicketStatus::Blocked],
            TicketStatus::Planned  => &[TicketStatus::Starting, TicketStatus::Blocked],
            TicketStatus::Starting => &[TicketStatus::Started, TicketStatus::Blocked],
            TicketStatus::Started  => &[TicketStatus::Reviewing, TicketStatus::Blocked],
            TicketStatus::Reviewing => &[TicketStatus::Reviewed, TicketStatus::Blocked],
            TicketStatus::Reviewed => &[TicketStatus::Done],
            TicketStatus::Done     => &[],
            TicketStatus::Blocked  => &[TicketStatus::Retrying, TicketStatus::Aborted],
            TicketStatus::Retrying => &[TicketStatus::Making, TicketStatus::Aborted],
            TicketStatus::RolledBack => &[TicketStatus::Making, TicketStatus::Aborted],
            TicketStatus::Aborted  => &[],
        }
    }
}
```

```rust
    fn handle_detect_omissions(&mut self, req: OmissionsRequest) -> Result<WorkflowResult, WorkflowError> {
        let round = self.round_manager.current_round();
        let mut omissions = OmissionsLedger::new(round);

        // Structural Inconsistency: 機械的検出
        let rfc_dag = RfcDag::from_fs(&req.rfc_path)?;
        let structural = self.detect_structural_inconsistency(&rfc_dag)?;
        omissions.omissions.extend(structural);

        // Implementation Missing / Contradiction / Deficiency: LLM検出
        if let Ok(llm_result) = self.detect_with_llm(&req.rfc_path) {
            omissions.omissions.extend(llm_result);
        }

        // Δ計算
        let score = self.deviation_calculator.calculate(&omissions);

        // OMISSIONS-<round>.json に保存
        let omissions_path = format!("OMISSIONS-{}.json", round);
        self.storage.write_json(&omissions_path, &omissions)?;

        // 観測ベクトル記録
        let obs = ObservationVector {
            r: round,
            v_count: rfc_dag.node_count() as u32,
            k_count: self.ticket_controller.total_count(),
            delta: score.delta,
            per_node_delta: score.per_node.clone(),
            duration_secs: 0, // 実測値に更新
            debt_index: self.malfeasance_controller.debt_index(),
            interventions: Vec::new(),
        };
        append_observation(&mut self.storage, &obs)?;

        // 収束判定
        if score.delta > 0.0 {
            let next = self.convergence_controller
                .determine_feedback_phase(&omissions);
            if let Some(target) = next {
                self.state.force_transition(target);
            }
        } else {
            self.state.force_transition(WorkflowState::Done);
        }

        Ok(WorkflowResult {
            message: format!("Omissions: Δ={} (M:{} C:{} U:{} X:{})",
                score.delta, score.components.m, score.components.c,
                score.components.u, score.components.x),
            state_changed: true,
        })
    }
```

### 4. DesignTree ガバナンス

#### 4.1 ノードモデル

```rust
// conver-core/src/designtree.rs

/// 設計判断ノードの種類。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub enum DesignNodeKind {
    DecisionGroup,
    ImplementationDetail,
    InfoOnly,
}

/// 設計判断の状態。
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum DesignStatus {
    Open,
    Resolved,
}

/// 質疑応答の記録。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct QuestionRecord {
    pub resolved_at: chrono::DateTime<chrono::Utc>,
    pub answer: String,
}

/// DesignTree ノード（再帰構造）。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DesignNode {
    pub id: String,
    pub title: String,
    pub status: DesignStatus,
    pub kind: DesignNodeKind,
    #[serde(default)]
    pub blocking: bool,
    #[serde(default)]
    pub depends_on: Vec<String>,
    #[serde(default)]
    pub covered_by_question_ids: Vec<String>,
    #[serde(default)]
    pub questions: Vec<QuestionRecord>,
    #[serde(default)]
    pub children: Vec<DesignNode>,
}

impl DesignNode {
    /// このノード以下のopen状態のノード数を再帰的にカウントする。
    pub fn count_open_recursive(&self) -> usize {
        let self_open = usize::from(self.status == DesignStatus::Open);
        let children_open: usize = self.children.iter().map(|c| c.count_open_recursive()).sum();
        self_open + children_open
    }

    /// 指定したIDの子孫ノードを検索する。
    pub fn find_mut(&mut self, id: &str) -> Option<&mut DesignNode> {
        if self.id == id {
            return Some(self);
        }
        for child in &mut self.children {
            if let Some(found) = child.find_mut(id) {
                return Some(found);
            }
        }
        None
    }
}
```

#### 4.2 DesignTree

```rust
/// DesignTree 全体。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DesignTree {
    pub version: u32,
    pub updated_at: chrono::DateTime<chrono::Utc>,
    pub nodes: Vec<DesignNode>,
}

impl DesignTree {
    pub fn new() -> Self {
        Self {
            version: 1,
            updated_at: chrono::Utc::now(),
            nodes: Vec::new(),
        }
    }

    /// 調査情報の内容から初期ノードを生成する。
    pub fn from_research(research: &str) -> Self {
        let mut tree = Self::new();
        // 調査情報からトピックを抽出し、初期ノードとして追加する
        // （実際の抽出はClaude Codeが行い、update-treeコマンドで追加される）
        tree
    }

    /// open状態の全ノード数をカウントする。
    pub fn count_open(&self) -> usize {
        self.nodes.iter().map(|n| n.count_open_recursive()).sum()
    }

    /// grill完了判定（第一級条件）。
    /// blockingフラグの値は完了条件に影響しない。
    pub fn is_grill_complete(&self) -> bool {
        self.count_open() == 0
    }

    /// 指定IDのノードを resolved に変更する。
    pub fn resolve_node(&mut self, id: &str, answer: &str) -> Result<(), TreeError> {
        for node in &mut self.nodes {
            if let Some(found) = node.find_mut(id) {
                found.status = DesignStatus::Resolved;
                found.questions.push(QuestionRecord {
                    resolved_at: chrono::Utc::now(),
                    answer: answer.to_string(),
                });
                self.updated_at = chrono::Utc::now();
                return Ok(());
            }
        }
        Err(TreeError::NodeNotFound(id.to_string()))
    }

    /// 親ノードに子ノードを追加する。
    pub fn add_child(&mut self, parent_id: &str, mut child: DesignNode) -> Result<(), TreeError> {
        // 子のIDが全ノードで一意であることを確認
        if self.find_node(&child.id).is_some() {
            return Err(TreeError::DuplicateId(child.id));
        }
        // 親が存在しない場合はルートに追加
        if parent_id.is_empty() {
            self.nodes.push(child);
            self.updated_at = chrono::Utc::now();
            return Ok(());
        }
        for node in &mut self.nodes {
            if let Some(found) = node.find_mut(parent_id) {
                child.depends_on.retain(|d| d != parent_id); // 自己依存防止
                found.children.push(child);
                self.updated_at = chrono::Utc::now();
                return Ok(());
            }
        }
        Err(TreeError::NodeNotFound(parent_id.to_string()))
    }

    /// IDでノードを検索する（読み取り専用）。
    pub fn find_node(&self, id: &str) -> Option<&DesignNode> {
        for node in &self.nodes {
            if node.id == id {
                return Some(node);
            }
            if let Some(found) = node.find_mut(id) {
                return Some(found);
            }
        }
        None
    }

    /// 指定IDのノードを削除する（子孫も全て削除）。
    pub fn delete_node(&mut self, id: &str) -> Result<(), TreeError> {
        let deleted = delete_recursive(&mut self.nodes, id);
        if deleted {
            // 第二層DAG（Tickets.json）も自動削除
            let tickets_path = PathBuf::from(id).join("Tickets.json");
            if tickets_path.exists() {
                std::fs::remove_file(tickets_path).ok();
            }
            self.updated_at = chrono::Utc::now();
            Ok(())
        } else {
            Err(TreeError::NodeNotFound(id.to_string()))
        }
    }
}

fn delete_recursive(nodes: &mut Vec<DesignNode>, id: &str) -> bool {
    if let Some(pos) = nodes.iter().position(|n| n.id == id) {
        nodes.remove(pos);
        return true;
    }
    for node in nodes.iter_mut() {
        if delete_recursive(&mut node.children, id) {
            return true;
        }
    }
    false
}
```

```rust
/// 1RFC分のチケットDAG。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TicketDag {
    pub rfc_id: String,
    pub version: u32,
    pub updated_at: chrono::DateTime<chrono::Utc>,
    pub tickets: Vec<TicketRecord>,
}

impl TicketDag {
    pub fn new(rfc_id: &str) -> Self {
        Self {
            rfc_id: rfc_id.to_string(),
            version: 1,
            updated_at: chrono::Utc::now(),
            tickets: Vec::new(),
        }
    }

    /// petgraphでDAG検証を実行。
    /// 循環がある場合は Err(CycleDetected)。
    /// 検証失敗時は構造化通知（循環パス・ノード一覧）を返す。
    pub fn validate_dag(&self) -> Result<DagValidationReport, TicketError> {
        use petgraph::graph::DiGraph;
        use petgraph::algo::is_cyclic_digraph;

        let mut graph = DiGraph::<&str, ()>::new();
        let indices: std::collections::HashMap<&str, _> = self.tickets
            .iter()
            .map(|t| (t.id.as_str(), graph.add_node(t.id.as_str())))
            .collect();

        for ticket in &self.tickets {
            for dep in &ticket.depends_on {
                if let Some(&from) = indices.get(ticket.id.as_str()) {
                    if let Some(&to) = indices.get(dep.as_str()) {
                        graph.add_edge(from, to, ());
                    }
                }
            }
        }

        if is_cyclic_digraph(&graph) {
            // 循環パスを検出してレポート
            let cycle_path = self.detect_cycle_path(&graph, &indices);
            return Err(TicketError::CycleDetectedWithPath(cycle_path));
        }

        Ok(DagValidationReport {
            valid: true,
            node_count: self.tickets.len(),
            edge_count: self.tickets.iter().map(|t| t.depends_on.len()).sum(),
            cycle_path: Vec::new(),
        })
    }

    /// トポロジカルソート順を返す。
    /// 依存のないチケットから順に並ぶ。
    pub fn topological_sort(&self) -> Result<Vec<&TicketRecord>, TicketError> {
        use petgraph::algo::toposort;
        use petgraph::graph::DiGraph;

        let mut graph = DiGraph::<usize, ()>::new();
        let indices: std::collections::HashMap<&str, _> = self.tickets
            .iter()
            .enumerate()
            .map(|(i, t)| (t.id.as_str(), graph.add_node(i)))
            .collect();

        for ticket in &self.tickets {
            for dep in &ticket.depends_on {
                if let Some(&from) = indices.get(ticket.id.as_str()) {
                    if let Some(&to) = indices.get(dep.as_str()) {
                        graph.add_edge(from, to, ());
                    }
                }
            }
        }

        match toposort(&graph, None) {
            Ok(sorted) => Ok(sorted.into_iter().map(|idx| &self.tickets[idx]).collect()),
            Err(_) => Err(TicketError::CycleDetected),
        }
    }

    /// 循環パスを検出する（構造化通知用）。
    fn detect_cycle_path<'a>(
        &self,
        _graph: &DiGraph<&'a str, ()>,
        indices: &std::collections::HashMap<&'a str, petgraph::graph::NodeIndex>,
    ) -> Vec<String> {
        // DFSで循環パスを探索
        let mut path = Vec::new();
        let mut visited = std::collections::HashSet::new();
        let mut in_stack = std::collections::HashSet::new();

        for ticket in &self.tickets {
            if !visited.contains(ticket.id.as_str()) {
                if self.dfs_cycle(ticket.id.as_str(), indices, &mut visited, &mut in_stack, &mut path) {
                    return path;
                }
            }
        }
        path
    }

    fn dfs_cycle(
        &self,
        node_id: &str,
        indices: &std::collections::HashMap<&str, petgraph::graph::NodeIndex>,
        visited: &mut std::collections::HashSet<String>,
        in_stack: &mut std::collections::HashSet<String>,
        path: &mut Vec<String>,
    ) -> bool {
        visited.insert(node_id.to_string());
        in_stack.insert(node_id.to_string());
        path.push(node_id.to_string());

        if let Some(ticket) = self.tickets.iter().find(|t| t.id == node_id) {
            for dep in &ticket.depends_on {
                if !visited.contains(dep.as_str()) {
                    if self.dfs_cycle(dep, indices, visited, in_stack, path) {
                        return true;
                    }
                } else if in_stack.contains(dep.as_str()) {
                    path.push(dep.clone());
                    return true;
                }
            }
        }

        path.pop();
        in_stack.remove(node_id);
        false
    }

    /// 入次数0の未完了チケット一覧（並列実行frontier）。
    pub fn compute_frontier(&self) -> Vec<&TicketRecord> {
        let sorted = self.topological_sort().ok();
        sorted.map(|vec| {
            vec.into_iter()
                .filter(|t| t.status == TicketStatus::Created)
                .filter(|t| {
                    t.depends_on.iter().all(|dep| {
                        self.tickets.iter()
                            .find(|t2| &t2.id == dep)
                            .map(|t2| t2.status == TicketStatus::Done)
                            .unwrap_or(false)
                    })
                })
                .collect()
        }).unwrap_or_default()
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DagValidationReport {

    pub edge_count: usize,
    pub cycle_path: Vec<String>,
```

#### 5.3 2段階編成フロー実装

```rust
impl TicketController {
    /// チケットDAG編成（2段階フロー）:
    ///
    /// Step 1: Claude Codeが骨格Tickets.jsonを出力（title + description + depends_on）
    /// Step 2: プログラムがDAG検証
    ///   → 成功: トポロジカルソート → Claude Codeに各詳細フィールドを埋めさせる
    ///   → 失敗: 問題点を構造化通知 → Claude Code再生成（上限3回）
    pub fn formulate(
        &mut self,
        rfc_node_path: &Path,
        runtime: &mut dyn RuntimeBackend,
        retry_limit: u32,
    ) -> Result<TicketDag, TicketError> {
        let tickets_path = rfc_node_path.join("Tickets.json");

        // Step 1: Claude Codeによる骨格生成
        let skeleton = self.extract_skeleton(rfc_node_path, runtime)?;

        // Step 1.5: DAG検証（リトライループ）
        let dag = self.validate_with_retry(skeleton, runtime, retry_limit)?;

        // Step 2: トポロジカルソート
        let sorted = dag.topological_sort()?;

        // Step 3: 詳細フィールドの書込
        let mut detailed = dag.clone();
        for ticket in sorted {
            let detail = runtime.extract_structured::<TicketDetail>(TicketDetailRequest {
                ticket_id: ticket.id.clone(),
                rfc_node_path: rfc_node_path.to_path_buf(),
            })?;
            if let Some(t) = detailed.tickets.iter_mut().find(|t| t.id == ticket.id) {
                t.acceptance_criteria = detail.acceptance_criteria;
                t.scope = detail.scope;
                t.verification = detail.verification;
                t.predicted_side_effects = detail.predicted_side_effects;
            }
        }

        // 保存
        let json = serde_json::to_string_pretty(&detailed)
            .map_err(|e| TicketError::JsonError(e))?;
        atomic_write(tickets_path, json.as_bytes())
            .map_err(|e| TicketError::IoError(e))?;

        Ok(detailed)
    }

    fn extract_skeleton(
        &self,
        rfc_node_path: &Path,
        runtime: &mut dyn RuntimeBackend,
    ) -> Result<TicketDag, TicketError> {
        let rfc_content = std::fs::read_to_string(rfc_node_path.join("RFC_???.md"))
            .map_err(|_| TicketError::RfcNotFound)?;

        let request = SkeletonRequest {
            rfc_content,
            rfc_node_path: rfc_node_path.to_path_buf(),
        };

        runtime.extract_structured::<TicketDag>(request)
            .map_err(|_| TicketError::SkeletonExtractionFailed)
    }

    fn validate_with_retry(
        &self,
        mut dag: TicketDag,
        runtime: &mut dyn RuntimeBackend,
        retry_limit: u32,
    ) -> Result<TicketDag, TicketError> {
        for attempt in 1..=retry_limit {
            match dag.validate_dag() {
                Ok(report) if report.valid => return Ok(dag),
                Err(e) => {
                    if attempt == retry_limit {
                        return Err(e);
                    }
                    // 問題点を構造化通知→Claude Code再生成
                    let feedback = match &e {
                        TicketError::CycleDetectedWithPath(path) => {
                            format!("Cycle detected: {}", path.join(" → "))
                        }
                        _ => "DAG validation failed".to_string(),
                    };
                    let request = RetryRequest {
                        previous_dag: dag.clone(),
                        feedback,
                    };
                    dag = runtime.extract_structured::<TicketDag>(request)
                        .map_err(|_| TicketError::RetryExhausted)?;
                }
            }
        }
        Err(TicketError::RetryExhausted)
    }
}
```

```rust
/// 乖離関数 Δ = αM + βC + γU + δX の計算機。
pub struct DeviationCalculator {
    pub alpha: f64, // Structural Inconsistency (X) デフォルト: 2.0
    pub beta: f64,  // Implementation Contradiction (C) デフォルト: 2.0
    pub gamma: f64, // Specification Deficiency (U) デフォルト: 1.0
    pub delta: f64, // Implementation Missing (M) デフォルト: 1.0
}

impl DeviationCalculator {
    pub fn from_settings(settings: &DeviationSettings) -> Self {
        Self {
            alpha: settings.alpha,
            beta: settings.beta,
            gamma: settings.gamma,
            delta: settings.delta,
        }
    }

    pub fn defaults() -> Self {
        Self {
            alpha: 2.0,
            beta: 2.0,
            gamma: 1.0,
            delta: 1.0,
        }
    }

    /// Δを計算する。
    pub fn calculate(&self, omissions: &OmissionsLedger) -> DeviationScore {
        let m = omissions.count_by_kind(OmissionKind::ImplementationMissing);
        let c = omissions.count_by_kind(OmissionKind::ImplementationContradiction);
        let u = omissions.count_by_kind(OmissionKind::SpecificationDeficiency);
        let x = omissions.count_by_kind(OmissionKind::StructuralInconsistency);

        let delta = self.alpha * x as f64
                  + self.beta * c as f64
                  + self.gamma * u as f64
                  + self.delta * m as f64;

        DeviationScore {
            delta,
            components: DeviationComponents { m, c, u, x },
            per_node: Vec::new(), // RFCノード別の乖離は呼出し元で設定
        }
    }
}
```

```rust
        }
    }

    /// omissions の種類に応じてフィードバック先の大域状態を決定する。
    ///
    /// | 乖離の種類 | フィードバック先 | 意味 |
    /// |-----------|----------------|------|
    /// | Structural Inconsistency (X) | ChecklistPending | Phase 2: RFCツリー再構成 |
    /// | Specification Deficiency (U) | Grilling | Phase 1: 頂点RFC改訂 |
    /// | Implementation Missing (M) | ChecklistApproved | Phase 4: チケット再実行 |
    /// | Implementation Contradiction (C) | ChecklistApproved | Phase 4: チケット再実行 |
    /// | なし (Δ=0) | None | 完了 |
    pub fn determine_feedback_phase(&self, omissions: &OmissionsLedger) -> Option<WorkflowState> {
        // X: 構造不整合は最優先（RFCツリー自体の問題）
        if omissions.has_kind(OmissionKind::StructuralInconsistency) {
            return Some(WorkflowState::ChecklistPending);
        }
        // U: 仕様不足はRFC改訂が必要
        if omissions.has_kind(OmissionKind::SpecificationDeficiency) {
            return Some(WorkflowState::Grilling);
        }
        // M/C: 実装不足・矛盾はチケット再実行
        if omissions.has_kind(OmissionKind::ImplementationMissing)
            || omissions.has_kind(OmissionKind::ImplementationContradiction)
        {
            return Some(WorkflowState::ChecklistApproved);
        }
        None
    }

    /// 1ループ分の収束処理を実行する。
    pub fn converge_round(
        &mut self,
        omissions: &OmissionsLedger,
        state: &mut WorkflowState,
    ) -> Result<ConvergenceResult, ConvergenceError> {
        let score = self.deviation_calculator.calculate(omissions);

        if score.delta == 0.0 {
            *state = WorkflowState::Done;
            return Ok(ConvergenceResult::Converged(score));
        }

        let round = self.round_manager.start_next_round()?;
        let next_phase = self.determine_feedback_phase(omissions)
            .unwrap_or(WorkflowState::Grilling);
        *state = next_phase;

        Ok(ConvergenceResult::Feedback { round, score, feedback_to: next_phase })
    }
}

#[derive(Debug)]
pub enum ConvergenceResult {
    Converged(DeviationScore),
    Feedback { round: u32, score: DeviationScore, feedback_to: WorkflowState },
}

#[derive(Debug, thiserror::Error)]
pub enum ConvergenceError {
    #[error("ループ上限超過: {current}/{max}")]
    LoopLimitExceeded { current: u32, max: u32 },
```

```rust
// conver-core/src/tree.rs
use petgraph::graph::DiGraph;
use petgraph::algo::is_cyclic_digraph;

/// DAGの辺の種類。
pub enum EdgeKind {
    Hierarchy, // 親子関係（ツリー構造、DAG検証不要）
    Depends,   // 依存関係（DAG検証対象）
}

/// RFCツリーDAG。
pub struct RfcDag {
    graph: DiGraph<RfcNode, EdgeKind>,
    nodes: Vec<RfcNode>,
}

/// RFCツリーノード（RFC_TREE.json のエントリに対応）。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RfcNode {
    pub id: String,
    pub title: String,
    pub path: String,
    pub status: String,
    pub children: Vec<String>,
    pub depends_on: Vec<String>,
    pub sha256: String,
}

impl RfcDag {
    /// RFC_TREE.json の文字列からRfcDagを構築する。
    pub fn from_json(json: &str) -> Result<Self, TreeError> {
        let tree: RfcTreeJson = serde_json::from_str(json)?;
        let mut graph = DiGraph::<usize, EdgeKind>::new();
        let mut nodes = Vec::new();

        // ノード追加
        let mut indices = std::collections::HashMap::new();
        for (i, node) in tree.nodes.iter().enumerate() {
            indices.insert(node.id.as_str(), graph.add_node(i));
            nodes.push(node.clone());
        }

        // 階層辺（children）
        for node in &tree.nodes {
            if let Some(&parent) = indices.get(node.id.as_str()) {
                for child_id in &node.children {
                    if let Some(&child) = indices.get(child_id.as_str()) {
                        graph.add_edge(parent, child, EdgeKind::Hierarchy);
                    }
                }
            }
        }

        // 依存辺（depends_on）
        for node in &tree.nodes {
            if let Some(&target) = indices.get(node.id.as_str()) {
                for dep_id in &node.depends_on {
                    if let Some(&source) = indices.get(dep_id.as_str()) {
                        graph.add_edge(source, target, EdgeKind::Depends);
                    }
                }
            }
        }

        Ok(Self { graph, nodes })
    }

    /// ファイルシステムからRFC_TREE.jsonを読み込む。
    pub fn from_fs(root_path: &Path) -> Result<Self, TreeError> {
        let path = root_path.join("RFC_TREE.json");
        let content = std::fs::read_to_string(&path)?;
        Self::from_json(&content)
    }

    /// DAG検証。依存辺のみ循環検出する。
    pub fn validate(&self) -> Result<DagValidationReport, TreeError> {
        let dep_graph = self.extract_dep_subgraph();
        if is_cyclic_digraph(&dep_graph) {
            return Ok(DagValidationReport {
                valid: false,
                cycle_path: self.detect_cycle(),
            });
        }
        self.validate_semantic_constraints()?;
        Ok(DagValidationReport {
            valid: true,
            cycle_path: Vec::new(),
        })
    }

    /// 意味的矛盾の検証（親→子の依存辺が存在しないこと）。
    fn validate_semantic_constraints(&self) -> Result<(), TreeError> {
        for edge in self.graph.edge_references() {
            if matches!(edge.weight(), EdgeKind::Depends) {
                let parent = edge.source();
                let child = edge.target();
                // 親→子の依存辺は禁止（子は親に依存してよい）
                if self.is_parent_of(parent, child) {
                    return Err(TreeError::ParentToChildDep);
                }
            }
        }
        Ok(())
    }

    /// 依存辺のみのサブグラフを抽出する。
    fn extract_dep_subgraph(&self) -> DiGraph<(), ()> {
        let mut sub = DiGraph::<(), ()>::new();
        let indices: Vec<_> = (0..self.graph.node_count())
            .map(|_| sub.add_node(()))
            .collect();
        for edge in self.graph.edge_references() {
            if matches!(edge.weight(), EdgeKind::Depends) {
                sub.add_edge(
                    indices[edge.source().index()],
                    indices[edge.target().index()],
                    (),
                );
            }
        }
        sub
    }

    fn is_parent_of(&self, parent: petgraph::graph::NodeIndex, child: petgraph::graph::NodeIndex) -> bool {
        self.graph.edges(parent).any(|e| {
            matches!(e.weight(), EdgeKind::Hierarchy) && e.target() == child
        })
    }

    fn detect_cycle(&self) -> Vec<String> {
        // DFSで循環パスを検出
        Vec::new() // 簡略化: 実装時はpetgraphのCycleDetectを使用
    }

    pub fn node_count(&self) -> usize {
        self.nodes.len()
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]
struct RfcTreeJson {
    version: u32,
    root_rfc_id: String,
    #[serde(default)]
    root_path: String,
    updated_at: String,
    nodes: Vec<RfcNode>,
}

#[derive(Debug, Clone)]
pub struct TreeError {
    pub kind: TreeErrorKind,
}

#[derive(Debug, Clone)]
pub enum TreeErrorKind {
    CycleDetected,
    ParentToChildDep,
    NodeNotFound,
    JsonParse(String),
    Io(String),
}

impl From<std::io::Error> for TreeError {
    fn from(e: std::io::Error) -> Self {
        Self { kind: TreeErrorKind::Io(e.to_string()) }
    }
}
```

### E. 設計資料（crates/conver/docs/）の利活用

`crates/conver/docs/` ディレクトリには本RFCおよび全子RFCの設計に先立って

| パス | 内容 | 本RFCとの関係 |

| `docs/conver-rfc-design-ja.md` | オリジナルRFC草案 | 本RFCの前身。grillセッションのインプットとして使用された |
| `docs/rfc_tree_self_converging_development_design.md` | 完全版設計記述 | 自己収束開発サイクルの理論的背景。数学的定式化の原典 |

| `docs/claude/commands/*.md` | 7種のスラッシュコマンド定義 | `conver init` で配布されるコマンドの参考実装。互換性検証に使用 |
| `docs/claude/scripts/grill-me-for-rfc/*.js` | 9種のgrill用スクリプト | conver-cli の各機能のリファレンス実装。Rust移植の検証用 |

| `docs/claude/scripts/tickets/review/*.js` | 3種のレビュー・品質スクリプト | conver-validation の品質ゲートのリファレンス実装 |
| `docs/claude/scripts/lib/*.js` | 4種の共通ライブラリ | 各crateの共通ロジックの参考実装 |

#### 利活用方法

1. **互換性検証**: `cargo run --bin test-run` の出力と従来スクリプトの実行結果を
   比較することで、Rust移植の正しさを機械的に検証できる。
2. **リファレンス実装**: 各Node.jsスクリプトは対応するRustモジュールの
   リファレンス実装として機能する。仕様の曖昧な部分は従来スクリプトの
   動作を確認することで補完できる。
3. **回帰テスト**: 従来スクリプトのテストケースをRustのテストコードとして
   再利用することで、機能退行を防止する。
