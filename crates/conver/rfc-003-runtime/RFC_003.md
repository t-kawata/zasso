# RFC_003: ランタイム抽象化（conver-runtime）

## Abstract

本RFCは、`conver` オーケストレータのランタイム抽象化レイヤ `conver-runtime` crate
の設計を規定する。本crateは Claude Code をデフォルトの実行バックエンドとしつつ、
`RuntimeBackend` / `RuntimeSession` / `StructuredPayloadExtractor` の3つのtraitに
より将来のbackend変更に備える。この抽象化により、Claude Code の非決定論的生成は
Runtime adapter 層で隔離され、上位の制御系（conver-core）には影響しない。

親RFC: [RFC_ROOT.md](crates/conver/RFC_ROOT.md)（conver: 決定論的 Rust オーケストレータ）
crate 実装先: `crates/conver/rfc-003-runtime/`
結合先: `conver-core` が本crateのtrait実装を利用する。

```text
crates/
  conver-core/      # RFC_002 — WorkflowController が本crateの
                    #           RuntimeBackend を保持・利用する
  conver-runtime/   ← 本RFCの実装範囲
```

## Motivation

conver の全ワークフローは Claude Code の非決定的な知的処理に依存する。grill 中の
質問生成、formulate-tickets でのチケットDAG骨格出力、omissions 検出でのRFC-実装
比較 — これらの処理はすべて Claude Code の実行を必要とする。しかし、この非決定性
は上位の制御系に伝播してはならない。本crateは以下の責務を負う：

1. **Runtime抽象化**: `RuntimeBackend` / `RuntimeSession` trait により、Claude Code
   と将来のbackendを同一インターフェースで扱う。制御系はbackendの種類を意識しない。
2. **非決定性の隔離**: Claude Code の非決定的出力は strict structured-output
   extraction と retry 戦略により、決定論的な構造化データに変換される。
   変換に失敗した場合も concrete failure reason が上位に伝わる。
3. **協力的中断**: 実行中のセッションを協力的に cancel し、状態を破棄しない。
   force-kill は行わず、SIGTERM による graceful shutdown を原則とする。
4. **イベントストリーム**: バックエンドからの生出力を `StdoutChunk` / `Progress` /
   `StructuredCandidate` / `Completed` 等の型付けされたイベントに正規化する。
5. **タイムアウト管理**: 長時間実行セッションのタイムアウトを監視し、設定された
   制限を超えた場合は自動キャンセルする。

```rust
// 目標とする使用イメージ（conver-core からの呼出し）
let request = RuntimeRequest::new("/grill-me-for-rfc ./research ./output")
    .with_timeout(settings.runtime.request_timeout_seconds);

let mut session = runtime.start_run(request)?;

loop {
    for event in session.stream_events()? {
        match event {
            RuntimeEvent::Progress { message } => ui.show_progress(&message),
            RuntimeEvent::StructuredCandidate(json) => candidates.push(json),
            RuntimeEvent::Completed => break,
            RuntimeEvent::StdoutChunk(s) => log::debug!("[claude] {}", s),
            RuntimeEvent::StderrChunk(s) => log::warn!("[claude:stderr] {}", s),
        }
    }
    if session.is_done()? { break; }
    std::thread::sleep(Duration::from_millis(100));
}

let result = session.await_result()?;
let payload: TicketDag = extractor.extract_structured(&result.text)
    .map_err(|e| WorkflowError::ExtractionFailed(e.to_string()))?;
```

### 2. RuntimeBackend trait

実行backendの抽象化。各backendはこのtraitを実装し、自身が生成するセッションの
具象型を関連型として宣言する。

```rust
// conver-runtime/src/backend.rs
use crate::session::RuntimeSession;
use crate::error::RuntimeError;

/// 実行backendの抽象化。
///
/// # 型パラメータ
/// - `Session`: このbackendが生成するセッションの具象型。
///   `RuntimeSession` trait を実装する必要がある。
///
/// # 実装例
/// ```ignore
/// impl RuntimeBackend for ClaudeCodeBackend {
///     type Session = ClaudeSession;
///     fn start_run(&self, req: RuntimeRequest) -> Result<ClaudeSession, RuntimeError> {
///         // ...
///     }
/// }
/// ```
pub trait RuntimeBackend {
    type Session: RuntimeSession;

    /// 新しい実行セッションを開始する。
    fn start_run(&self, request: RuntimeRequest) -> Result<Self::Session, RuntimeError>;
}

/// 実行リクエスト。
///
/// 全backendに共通のリクエスト形式。backend固有のパラメータは
/// backendの設定構造体で指定する。
#[derive(Debug, Clone)]
pub struct RuntimeRequest {
    /// Claude Code に渡すslash-commandの内容。
    /// 例: "/grill-me-for-rfc ./research ./output"
    pub command_text: String,
    /// セッションに注入する追加コンテキスト（RFC内容等）。
    pub context: Option<String>,
    /// タイムアウト（秒）。0の場合はタイムアウト無効。
    /// デフォルト: 1800（30分）。
    pub timeout_secs: u64,
    /// 最大リトライ回数（抽出失敗時の再試行）。
    /// デフォルト: 3。
    pub max_retries: u32,
}

impl RuntimeRequest {
    /// 最小構成でリクエストを生成する。
    pub fn new(command_text: impl Into<String>) -> Self {
        Self {
            command_text: command_text.into(),
            context: None,
            timeout_secs: 1800,
            max_retries: 3,
        }
    }

    /// コンテキストを設定する（builderパターン）。
    pub fn with_context(mut self, context: impl Into<String>) -> Self {
        self.context = Some(context.into());
        self
    }

    /// タイムアウトを設定する（builderパターン）。
    pub fn with_timeout(mut self, secs: u64) -> Self {
        self.timeout_secs = secs;
        self
    }

    /// 最大リトライ回数を設定する（builderパターン）。
    pub fn with_max_retries(mut self, retries: u32) -> Self {
        self.max_retries = retries;
        self
    }

    /// このリクエストを環境変数経由で子プロセスに渡すための
    /// 環境変数マップを生成する。
    pub fn to_env_map(&self) -> Vec<(&str, String)> {
        let mut env = Vec::new();
        if let Some(ctx) = &self.context {
            env.push(("CONVER_CONTEXT", ctx.clone()));
        }
        env.push(("CONVER_TIMEOUT", self.timeout_secs.to_string()));
        env.push(("CONVER_MAX_RETRIES", self.max_retries.to_string()));
        env
    }
}

impl std::fmt::Display for RuntimeRequest {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "RuntimeRequest(timeout={}s, retries={})",
            self.timeout_secs, self.max_retries)
    }
}
```

### 3. RuntimeSession trait

実行中のセッションを表現する。イベントのストリーム取得、協力的キャンセル、
完了待機の3操作を提供する。

```rust
// conver-runtime/src/session.rs
use crate::event::RuntimeEvent;
use crate::error::RuntimeError;

/// 実行中のセッションの状態。
#[derive(Debug, Clone, PartialEq)]
pub enum SessionState {
    /// 実行中（イベントストリーム可能）。
    Running,
    /// キャンセル要求済み（backendが停止処理中）。
    Cancelling,
    /// 完了（await_result で結果取得可能）。
    Completed,
    /// エラー発生（await_result でエラー詳細取得可能）。
    Failed,
}

/// 実行中のセッション。
///
/// # ライフサイクル
/// ```text
/// start_run() → Running → stream_events()* → Cancelling → Completed
///                                                    → Failed
/// ```
///
/// # 注意
/// - `stream_events()` はブロッキングせず、即座に利用可能なイベントの
///   バッチを返す。空Vecを返すことは正常動作。
/// - `cancel()` は backend に協力的停止を要求し、即座に戻る。
///   実際の停止は非同期に進行する。
/// - `await_result()` はセッションが完了するまでブロッキングする。
pub trait RuntimeSession {
    /// セッションの現在の状態を返す。
    fn state(&self) -> SessionState;

    /// セッションが完了しているか。
    fn is_done(&self) -> Result<bool, RuntimeError> {
        Ok(self.state() == SessionState::Completed
            || self.state() == SessionState::Failed)
    }

    /// 即座に利用可能なイベントのバッチを返す。
    /// ブロッキングしない。空Vecを返すことがある。
    /// セッション完了時は末尾に RuntimeEvent::Completed を含む。
    fn stream_events(&mut self) -> Result<Vec<RuntimeEvent>, RuntimeError>;

    /// 協力的キャンセルを要求する。
    /// backendは可能な限り早く安全な境界で停止する。
    /// force-killは行わない（SIGKILLではなくSIGTERM）。
    /// 戻り値はキャンセル要求の成功/失敗を示す。
    fn cancel(&mut self) -> Result<(), RuntimeError>;

    /// セッションの完了を待ち、最終結果を取得する。
    /// `cancel()` 後に呼び出した場合、部分結果を返す。
    /// このメソッドはブロッキングする。
    fn await_result(self) -> Result<RuntimeResult, RuntimeError>;
}

/// セッションの最終結果。
#[derive(Debug, Clone)]
pub struct RuntimeResult {
    /// セッションの全stdoutテキスト（行単位で連結）。
    pub text: String,
    /// 抽出された構造化ペイロードの候補文字列。
    /// commit_checkpoint で検証されるまでは tentative。
    pub structured_candidates: Vec<String>,
    /// セッションが正常完了したか。
    pub completed: bool,
    /// キャンセルされたか。
    pub cancelled: bool,
    /// 実行時間（秒）。
    pub duration_secs: u64,
    /// 抽出されたJSONブロック数。
    pub json_block_count: usize,
}

impl RuntimeResult {
    /// 空の結果（テスト用）。
    pub fn empty() -> Self {
        Self {
            text: String::new(),
            structured_candidates: Vec::new(),
            completed: true,
            cancelled: false,
            duration_secs: 0,
            json_block_count: 0,
        }
    }
}
```

### 4. RuntimeEvent モデル

バックエンドからの出力を型付けされたイベントに正規化する。

```rust
// conver-runtime/src/event.rs

/// ランタイムからのイベント。
///
/// 各variantは backend の生出力から正規化される。
/// `StructuredCandidate` は commit_checkpoint で検証されるまでは
/// tentative（非authoritative）として扱われる。
#[derive(Debug, Clone)]
pub enum RuntimeEvent {
    /// stdout へのテキスト出力。
    StdoutChunk(String),

    /// stderr へのテキスト出力（警告・診断メッセージ等）。
    StderrChunk(String),

    /// 構造化ペイロードの候補（JSONブロック等）。
    /// commit_checkpoint 通過前は tentative。
    StructuredCandidate(String),

    /// 進捗報告（UI表示用）。
    Progress {
        message: String,
    },

    /// セッション正常完了。
    /// このイベント以降は stream_events は空Vecを返す。
    Completed,
}

impl RuntimeEvent {
    /// 終端イベントか。
    pub fn is_terminal(&self) -> bool {
        matches!(self, RuntimeEvent::Completed)
    }

    /// 表示用の短い要約（最大80文字）。
    pub fn summary(&self) -> String {
        match self {
            RuntimeEvent::StdoutChunk(s) => {
                let trimmed = s.trim();
                if trimmed.len() > 77 {
                    format!("{}...", &trimmed[..77])
                } else {
                    trimmed.to_string()
                }
            }
            RuntimeEvent::StderrChunk(s) => {
                format!("[stderr] {}", s.trim())
            }
            RuntimeEvent::StructuredCandidate(s) => {
                format!("[json] {} bytes", s.len())
            }
            RuntimeEvent::Progress { message } => message.clone(),
            RuntimeEvent::Completed => "[completed]".to_string(),
        }
    }
}
```

### 5. 抽出器（Extractor）

バックエンドの生テキストから構造化データを抽出する。この層が非決定論的出力を
決定論的データ構造に変換する唯一の経路である。

#### 5.1 StructuredPayloadExtractor trait

```rust
// conver-runtime/src/extractor.rs

/// 構造化ペイロード抽出器。
///
/// 型パラメータ `T` は抽出対象の型（`serde::Deserialize` 実装必須）。
pub trait StructuredPayloadExtractor {
    /// 生テキストから型 `T` の値を抽出する。
    ///
    /// # エラー
    /// 抽出失敗時は `ExtractError` を返す。エラーには以下を含む：
    /// - `reason`: 具体的な失敗理由
    /// - `expected_schema`: 期待されるJSON schemaの説明
    /// - `sample`: 抽出対象テキストの先頭200文字
    fn extract_structured<T: serde::de::DeserializeOwned>(
        &self,
        text: &str,
    ) -> Result<T, ExtractError>;
}

/// 抽出エラー。
#[derive(Debug, Clone)]
pub struct ExtractError {
    /// エラー理由の説明（"JSON block not found", "parse error: ..."）。
    pub reason: String,
    /// 期待されるschemaの説明（Claude Codeへのフィードバック用）。
    pub expected_schema: String,
    /// 抽出を試みた生テキストの先頭200文字。
    pub sample: String,
}

impl std::fmt::Display for ExtractError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "ExtractError: {} (expected: {})",
            self.reason, self.expected_schema)
    }
}

impl std::error::Error for ExtractError {}
```

#### 5.2 JsonExtractor（デフォルト抽出器）

```json
```json
{"key": "value"}
```
```
という3種類の書式をサポートする。

```rust
/// JSON抽出のデフォルト実装。
///
/// 以下の3形式をサポート:
/// 1. ```json ... ``` コードブロック（最優先）
/// 2. 最上位の `{` から対応する `}` まで
/// 3. 行単位のJSON（1行が完全なJSONオブジェクト）
pub struct JsonExtractor;

impl JsonExtractor {
    pub fn new() -> Self { Self }

    /// テキストからJSONブロックを抽出する。
    ///
    /// 優先順位:
    /// 1. ```json ... ``` フェンスドブロック
    /// 2. 最初の `{` から対応する `}` まで
    /// 3. 最長のJSONらしい行
    fn extract_json_text(&self, text: &str) -> Option<String> {
        // 優先1: ```json フェンスドブロック
        if let Some(block) = self.extract_fenced_block(text) {
            return Some(block);
        }
        // 優先2: 対応する `{}`
        if let Some(braces) = self.extract_balanced_braces(text) {
            return Some(braces);
        }
        // 優先3: 行単位のJSON
        self.extract_line_json(text)
    }

    /// ```json ... ``` ブロックを抽出する。
    fn extract_fenced_block(&self, text: &str) -> Option<String> {
        let lines: Vec<&str> = text.lines().collect();
        let mut i = 0;
        while i < lines.len() {
            if lines[i].trim() == "```json" {
                let mut block = Vec::new();
                i += 1;
                while i < lines.len() && lines[i].trim() != "```" {
                    block.push(lines[i]);
                    i += 1;
                }
                if !block.is_empty() {
                    return Some(block.join("\n"));
                }
            }
            i += 1;
        }
        None
    }

    /// 最初の `{` から対応する `}` までを抽出する。
    fn extract_balanced_braces(&self, text: &str) -> Option<String> {
        if let Some(start) = text.find('{') {
            let mut depth = 0u32;
            for (i, c) in text[start..].char_indices() {
                match c {
                    '{' => depth += 1,
                    '}' => {
                        depth -= 1;
                        if depth == 0 {
                            return Some(text[start..=start + i].to_string());
                        }
                    }
                    _ => {}
                }
            }
        }
        None
    }

    /// 1行が完全なJSONとみなせる行を抽出する。
    fn extract_line_json(&self, text: &str) -> Option<String> {
        let mut best: Option<(usize, &str)> = None;
        for line in text.lines() {
            let trimmed = line.trim();
            if trimmed.starts_with('{') && trimmed.ends_with('}') {
                let len = trimmed.len();
                if best.as_ref().map_or(true, |&(l, _)| len > l) {
                    best = Some((len, trimmed));
                }
            }
        }
        best.map(|(_, s)| s.to_string())
    }
}

impl StructuredPayloadExtractor for JsonExtractor {
    fn extract_structured<T: serde::de::DeserializeOwned>(
        &self, text: &str,
    ) -> Result<T, ExtractError> {
        let json_str = self.extract_json_text(text).ok_or_else(|| ExtractError {
            reason: "JSON block not found in output".to_string(),
            expected_schema: std::any::type_name::<T>().to_string(),
            sample: text.chars().take(200).collect(),
        })?;

        serde_json::from_str::<T>(&json_str).map_err(|e| ExtractError {
            reason: format!("JSON parse error: {}", e),
            expected_schema: std::any::type_name::<T>().to_string(),
            sample: json_str.chars().take(200).collect(),
        })
    }
}
```

#### 5.3 MarkdownExtractor（Markdownからの抽出補助）

```rust
/// Markdownテキストからコードブロックやテーブルを抽出する。
pub struct MarkdownExtractor;

impl MarkdownExtractor {
    pub fn new() -> Self { Self }

    /// 指定された言語のコードブロックを全て抽出する。
    pub fn extract_code_blocks(&self, text: &str, language: &str) -> Vec<String> {
        let mut blocks = Vec::new();
        let lines: Vec<&str> = text.lines().collect();
        let mut i = 0;
        while i < lines.len() {
            let trimmed = lines[i].trim();
            if trimmed == &format!("```{}", language) || trimmed == "```" {
                let mut block = Vec::new();
                i += 1;
                while i < lines.len() && lines[i].trim() != "```" {
                    block.push(lines[i]);
                    i += 1;
                }
                if !block.is_empty() {
                    blocks.push(block.join("\n"));
                }
            }
            i += 1;
        }
        blocks
    }

    /// テキスト内の最初のMarkdown見出し（#）を抽出する。
    pub fn extract_first_heading(&self, text: &str) -> Option<String> {
        text.lines()
            .find(|l| l.trim().starts_with('#'))
            .map(|l| l.trim().trim_start_matches('#').trim().to_string())
    }
}

#### 5.4 CompositeExtractor（複数抽出器のフォールバック連鎖）

```rust
/// 複数の抽出器を直列に試行する。
/// 先頭の抽出器が失敗した場合、次の抽出器にフォールバックする。
pub struct CompositeExtractor {
    extractors: Vec<Box<dyn StructuredPayloadExtractor>>,
}

impl CompositeExtractor {
    pub fn new(extractors: Vec<Box<dyn StructuredPayloadExtractor>>) -> Self {
        Self { extractors }
    }

    /// デフォルト構成: JsonExtractor のみ
    pub fn default_json() -> Self {
        Self {
            extractors: vec![Box::new(JsonExtractor::new())],
        }
    }

    /// 寛容な構成: TomlExtractor → JsonExtractor の順
    pub fn lenient() -> Self {
        Self {
            extractors: vec![
                Box::new(JsonExtractor::new()),
            ],
        }
    }
}

impl StructuredPayloadExtractor for CompositeExtractor {
    fn extract_structured<T: serde::de::DeserializeOwned>(
        &self, text: &str,
    ) -> Result<T, ExtractError> {
        let mut last_error = None;
        for extractor in &self.extractors {
            match extractor.extract_structured::<T>(text) {
                Ok(payload) => return Ok(payload),
                Err(e) => last_error = Some(e),
            }
        }
        Err(last_error.unwrap_or_else(|| ExtractError {
            reason: "all extractors failed".into(),
            expected_schema: std::any::type_name::<T>().to_string(),
            sample: text.chars().take(200).collect(),
        }))
    }
}
```

#### 5.5 RetryExtractor（リトライ戦略）

```rust
/// リトライ付き抽出器。
///
/// 抽出失敗時に regenerate クロージャを呼び出し、Claude Code に
/// 修正を依頼する。最大 `max_attempts` 回試行する。
///
/// # リトライ動作
/// - 通常リトライ（attempt < max_attempts）:
///   concrete failure reason + 期待schema を Clude Code に送信
/// - 最終試行（attempt == max_attempts）:
///   reformat-only mode（新規推論禁止、構造補正のみを要求）
/// - 全試行失敗: 最後の ExtractError を返す
pub struct RetryExtractor {
    inner: Box<dyn StructuredPayloadExtractor>,
    max_attempts: u32,
}

impl RetryExtractor {
    pub fn new(extractor: Box<dyn StructuredPayloadExtractor>, max_attempts: u32) -> Self {
        Self { inner: extractor, max_attempts }
    }

    /// リトライループ付きで抽出する。
    ///
    /// `regenerate` クロージャは Claude Code にフィードバックを送信し、
    /// 修正されたテキストを返す。
    pub fn extract_with_retry<T, F>(
        &self, text: &str, mut regenerate: F,
    ) -> Result<T, ExtractError>
    where
        T: serde::de::DeserializeOwned,
        F: FnMut(RetryFeedback) -> Result<String, RuntimeError>,
    {
        let mut current_text = text.to_string();

        for attempt in 1..=self.max_attempts {
            // 通常抽出を試行
            match self.inner.extract_structured::<T>(&current_text) {
                Ok(payload) => return Ok(payload),
                Err(err) if attempt < self.max_attempts => {
                    // 通常リトライ
                    let feedback = RetryFeedback {
                        attempt,
                        max_attempts: self.max_attempts,
                        failure_reason: err.reason.clone(),
                        expected_schema: err.expected_schema.clone(),
                        reformat_only: false,
                        text_sample: err.sample.clone(),
                    };
                    match regenerate(feedback) {
                        Ok(new_text) => current_text = new_text,
                        Err(_) => return Err(err),
                    }
                }
                Err(err) => {
                    // 最終試行: reformat-only
                    let feedback = RetryFeedback {
                        attempt,
                        max_attempts: self.max_attempts,
                        failure_reason: err.reason.clone(),
                        expected_schema: err.expected_schema.clone(),
                        reformat_only: true,
                        text_sample: err.sample.clone(),
                    };
                    // reformat-only でも失敗した場合、元のエラーを返す
                    if let Ok(reformatted) = regenerate(feedback) {
                        if let Ok(payload) = self.inner.extract_structured::<T>(&reformatted) {
                            return Ok(payload);
                        }
                    }
                    return Err(err);
                }
            }
        }

        unreachable!("retry loop should always terminate")
    }
}

/// Claude Code へのリトライフィードバック。
///
/// この構造体の `Display` 実装が Claude Code に送信される
/// フィードバックメッセージを生成する。
#[derive(Debug, Clone)]
pub struct RetryFeedback {
    /// 今回の試行回数（1始まり）。
    pub attempt: u32,
    /// 最大試行回数。
    pub max_attempts: u32,
    /// 抽出失敗の具体的理由。
    pub failure_reason: String,
    /// 期待されるschemaの説明。
    pub expected_schema: String,
    /// true の場合、新規推論禁止・構造補正のみ。
    pub reformat_only: bool,
    /// 抽出に失敗したテキストのサンプル。
    pub text_sample: String,
}

impl std::fmt::Display for RetryFeedback {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        writeln!(f, "=== JSON Extraction Feedback ===")?;
        writeln!(f, "Attempt: {}/{}", self.attempt, self.max_attempts)?;
        writeln!(f, "Failure: {}", self.failure_reason)?;
        writeln!(f, "Expected schema: {}", self.expected_schema)?;
        if self.reformat_only {
            writeln!(f, "Mode: REFORMAT ONLY")?;
            writeln!(f, "Do NOT generate new reasoning. Correct structure only.")?;
        } else {
            writeln!(f, "Mode: RETRY")?;
            writeln!(f, "Fix the JSON output to match the expected schema.")?;
        }
        writeln!(f, "--- Failed text sample (first 100 chars) ---")?;
        writeln!(f, "{}", &self.text_sample.chars().take(100).collect::<String>())?;
        writeln!(f, "---")?;
        Ok(())
    }
}

// conver-runtime/src/claude.rs
use std::process::{Child, Command, Stdio};
use std::io::{BufRead, BufReader};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::time::Instant;

use crate::backend::{RuntimeBackend, RuntimeRequest};
use crate::session::{RuntimeSession, RuntimeResult, SessionState};
use crate::event::RuntimeEvent;
use crate::error::RuntimeError;

/// Claude Code 実行backend。
///
/// `claude --print <command_text>` を子プロセスとして実行する。
/// stdout / stderr を分離して収集し、行単位のイベントとして
/// 上位に提供する。
pub struct ClaudeCodeBackend {
    /// `claude` バイナリへのパス（デフォルト: "claude"）。
    claude_path: String,
    /// 各セッションに渡す追加環境変数。
    extra_env: Vec<(String, String)>,
}

impl ClaudeCodeBackend {
    /// デフォルト設定で backend を生成する。
    pub fn new() -> Self {
        Self {
            claude_path: "claude".to_string(),
            extra_env: Vec::new(),
        }
    }

    /// `claude` バイナリのパスを指定する。
    pub fn with_claude_path(mut self, path: impl Into<String>) -> Self {
        self.claude_path = path.into();
        self
    }

    /// 追加の環境変数を設定する。
    pub fn with_env(mut self, key: impl Into<String>, value: impl Into<String>) -> Self {
        self.extra_env.push((key.into(), value.into()));
        self
    }
}

impl RuntimeBackend for ClaudeCodeBackend {
    type Session = ClaudeSession;

    fn start_run(&self, request: RuntimeRequest) -> Result<Self::Session, RuntimeError> {
        let mut cmd = Command::new(&self.claude_path);
        cmd.arg("--print");
        cmd.arg(&request.command_text);
        cmd.stdout(Stdio::piped());
        cmd.stderr(Stdio::piped());

        // 環境変数の設定
        for (key, value) in request.to_env_map() {
            cmd.env(key, value);
        }
        for (key, value) in &self.extra_env {
            cmd.env(key, value);
        }

        let child = cmd.spawn().map_err(|e| {
            RuntimeError::SpawnFailed(format!(
                "Failed to spawn `{}`: {}. Is Claude Code installed?",
                self.claude_path, e
            ))
        })?;

        let start_time = Instant::now();

        Ok(ClaudeSession {
            child: Some(child),
            state: Arc::new(AtomicBool::new(false)), // false = running
            cancelled: Arc::new(AtomicBool::new(false)),
            output: String::new(),
            stderr_output: String::new(),
            structured_candidates: Vec::new(),
            start_time,
            timeout_secs: request.timeout_secs,
            json_block_count: 0,
        })
    }
}

/// Claude Code 実行セッション。
pub struct ClaudeSession {
    child: Option<Child>,
    /// セッション完了フラグ（子プロセス終了時に true）。
    state: Arc<AtomicBool>,
    /// キャンセル要求フラグ。
    cancelled: Arc<AtomicBool>,
    /// 蓄積されたstdout。
    output: String,
    /// 蓄積されたstderr。
    stderr_output: String,
    /// 検出されたJSON候補。
    structured_candidates: Vec<String>,
    /// 開始時刻（タイムアウト計算用）。
    start_time: Instant,
    /// タイムアウト（秒）。0=無効。
    timeout_secs: u64,
    /// 検出されたJSONブロック数。
    json_block_count: usize,
}

impl ClaudeSession {
    /// 子プロセスのstdoutから利用可能な行を読み取る。
    fn read_stdout(&mut self) -> Result<Vec<RuntimeEvent>, RuntimeError> {
        let mut events = Vec::new();

        if let Some(ref mut child) = self.child {
            if let Some(ref mut stdout) = child.stdout {
                let reader = BufReader::new(stdout);
                // 利用可能な行を全て読み取る（ブロッキングしない）
                for line in reader.lines() {
                    let line = match line {
                        Ok(l) => l,
                        Err(ref e) if e.kind() == std::io::ErrorKind::WouldBlock => break,
                        Err(e) => return Err(RuntimeError::StreamError(e.to_string())),
                    };

                    self.output.push_str(&line);
                    self.output.push('\n');

                    // JSON候補の検出
                    let trimmed = line.trim();
                    if trimmed.starts_with('{') || trimmed.starts_with("```json") {
                        self.structured_candidates.push(line.clone());
                        self.json_block_count += 1;
                        events.push(RuntimeEvent::StructuredCandidate(line));
                    } else {
                        events.push(RuntimeEvent::StdoutChunk(line));
                    }

                    // キャンセルチェック（毎行）
                    if self.cancelled.load(Ordering::Relaxed) {
                        break;
                    }
                }
            }
        }

        Ok(events)
    }

    /// 子プロセスのstderrから利用可能な行を読み取る。
    fn read_stderr(&mut self) -> Result<Vec<RuntimeEvent>, RuntimeError> {
        let mut events = Vec::new();

        if let Some(ref mut child) = self.child {
            if let Some(ref mut stderr) = child.stderr {
                let reader = BufReader::new(stderr);
                for line in reader.lines() {
                    let line = match line {
                        Ok(l) => l,
                        Err(ref e) if e.kind() == std::io::ErrorKind::WouldBlock => break,
                        Err(e) => return Err(RuntimeError::StreamError(e.to_string())),
                    };
                    self.stderr_output.push_str(&line);
                    self.stderr_output.push('\n');
                    events.push(RuntimeEvent::StderrChunk(line));
                }
            }
        }

        Ok(events)
    }

    /// 子プロセスの生存確認とタイムアウトチェック。
    fn check_timeout(&self) -> Result<(), RuntimeError> {
        if self.timeout_secs > 0 {
            let elapsed = self.start_time.elapsed().as_secs();
            if elapsed > self.timeout_secs {
                return Err(RuntimeError::Timeout(self.timeout_secs));
            }
        }
        Ok(())
    }
}

impl RuntimeSession for ClaudeSession {
    fn state(&self) -> SessionState {
        if self.cancelled.load(Ordering::Relaxed) {
            return SessionState::Cancelling;
        }
        if self.state.load(Ordering::Relaxed) {
            return SessionState::Completed;
        }
        SessionState::Running
    }

    fn stream_events(&mut self) -> Result<Vec<RuntimeEvent>, RuntimeError> {
        // タイムアウトチェック
        self.check_timeout()?;

        let mut events = Vec::new();

        // stderr の読み取り（先に行う）
        events.extend(self.read_stderr()?);

        // stdout の読み取り
        events.extend(self.read_stdout()?);

        // プロセス終了チェック
        if let Some(ref mut child) = self.child {
            match child.try_wait() {
                Ok(Some(_status)) => {
                    self.state.store(true, Ordering::Relaxed);
                    self.child = None;
                    events.push(RuntimeEvent::Completed);
                }
                Ok(None) => {
                    // まだ実行中
                    if events.is_empty() {
                        // イベントがない場合でも、キャンセル状態なら完了扱い
                        if self.cancelled.load(Ordering::Relaxed) {
                            self.state.store(true, Ordering::Relaxed);
                            events.push(RuntimeEvent::Completed);
                        }
                    }
                }
                Err(e) => {
                    self.state.store(true, Ordering::Relaxed);
                    return Err(RuntimeError::StreamError(e.to_string()));
                }
            }
        }

        Ok(events)
    }

    fn cancel(&mut self) -> Result<(), RuntimeError> {
        self.cancelled.store(true, Ordering::Relaxed);

        if let Some(ref child) = self.child {
            let pid = child.id();

            // Unix: SIGTERM で協力的停止
            #[cfg(unix)]
            {
                use std::os::unix::process::CommandExt;
                let result = unsafe { libc::kill(pid as i32, libc::SIGTERM) };
                if result != 0 {
                    let err = std::io::Error::last_os_error();
                    log::warn!("kill(SIGTERM, {}) failed: {}", pid, err);
                    // SIGTERM が失敗した場合 SIGKILL は使わない（協力的原則）
                }
            }

            // Windows: Ctrl+C 相当
            #[cfg(windows)]
            {
                let _ = child.kill();
            }
        }

        Ok(())
    }

    fn await_result(mut self) -> Result<RuntimeResult, RuntimeError> {
        let duration = self.start_time.elapsed().as_secs();

        // プロセス完了を待つ
        if let Some(ref mut child) = self.child {
            let wait_result = child.wait();
            self.state.store(true, Ordering::Relaxed);

            if let Err(e) = wait_result {
                if !self.cancelled.load(Ordering::Relaxed) {
                    return Err(RuntimeError::StreamError(e.to_string()));
                }
                // キャンセル済みの場合はエラーにしない
            }
        }

        Ok(RuntimeResult {
            text: std::mem::take(&mut self.output),
            structured_candidates: std::mem::take(&mut self.structured_candidates),
            completed: !self.cancelled.load(Ordering::Relaxed),
            cancelled: self.cancelled.load(Ordering::Relaxed),
            duration_secs: duration,
            json_block_count: self.json_block_count,
        })
    }
}

### 7. タイムアウト監視

```rust
// conver-runtime/src/timeout.rs
use std::sync::mpsc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::thread;
use std::time::Duration;

/// タイムアウト監視スレッド。
///
/// 指定された秒数後にキャンセルフラグをセットする。
pub struct TimeoutMonitor {
    cancelled: Arc<AtomicBool>,
    handle: Option<thread::JoinHandle<()>>,
}

impl TimeoutMonitor {
    /// 新しいタイムアウト監視を開始する。
    ///
    /// `timeout_secs` 秒後に `cancel_flag` を true に設定する。
    /// `timeout_secs` が 0 の場合は監視しない。
    pub fn start(timeout_secs: u64, cancel_flag: Arc<AtomicBool>) -> Self {
        if timeout_secs == 0 {
            return Self { cancelled: cancel_flag, handle: None };
        }

        let cancelled = cancel_flag.clone();
        let handle = thread::spawn(move || {
            thread::sleep(Duration::from_secs(timeout_secs));
            cancelled.store(true, Ordering::Relaxed);
            log::info!("TimeoutMonitor: {}秒経過、キャンセルフラグをセット", timeout_secs);
        });

        Self { cancelled: cancel_flag, handle: Some(handle) }
    }

    /// タイムアウト発生済みか。
    pub fn is_timed_out(&self) -> bool {
        self.cancelled.load(Ordering::Relaxed)
    }
}

/// 通知付きタイムアウト監視。
pub struct NotifyingTimeoutMonitor {
    timeout_secs: u64,
    sender: mpsc::Sender<()>,
}

impl NotifyingTimeoutMonitor {
    pub fn new(timeout_secs: u64) -> (Self, mpsc::Receiver<()>) {
        let (tx, rx) = mpsc::channel();
        (Self { timeout_secs, sender: tx }, rx)
    }

    pub fn start(self) -> thread::JoinHandle<()> {
        thread::spawn(move || {
            thread::sleep(Duration::from_secs(self.timeout_secs));
            let _ = self.sender.send(());
        })
    }
}

        for event in events {
            Self::log_event(event);
        }
    }

    fn retry_exhausts_attempts() {
        let ext = RetryExtractor::new(Box::new(JsonExtractor::new()), 5);
        let mut count = 0u32;
        let _: Result<serde_json::Value, _> = ext.extract_with_retry(
            "bad",
            |_| { count += 1; Err(RuntimeError::StreamError("fail".into())) },
        );
        assert_eq!(count, 5);

            reformat_only: true,

        let s = fb.to_string();
        assert!(s.contains("3/3"));
        assert!(s.contains("REFORMAT ONLY"));
        assert!(s.contains("Do NOT generate new reasoning"));

    #[test]
    fn request_builder_pattern() {
        let req = RuntimeRequest::new("/test")
            .with_context("important context")
            .with_timeout(300)
            .with_max_retries(5);

        assert_eq!(req.command_text, "/test");
        assert_eq!(req.context, Some("important context".into()));
        assert_eq!(req.timeout_secs, 300);
        assert_eq!(req.max_retries, 5);

    #[test]
    fn request_defaults() {
        let req = RuntimeRequest::new("/cmd");
        assert_eq!(req.timeout_secs, 1800);
        assert_eq!(req.max_retries, 3);
        assert!(req.context.is_none());

    #[test]
    fn request_to_env_map() {
        let req = RuntimeRequest::new("/cmd").with_context("ctx").with_timeout(60);
        let env = req.to_env_map();
        assert!(env.iter().any(|(k, _)| *k == "CONVER_CONTEXT"));
        assert!(env.iter().any(|(k, v)| *k == "CONVER_TIMEOUT" && v == "60"));
    }

    // ── RuntimeResult ──

    #[test]
    fn empty_result() {
        let r = RuntimeResult::empty();
        assert!(r.completed);
        assert!(!r.cancelled);
        assert_eq!(r.text, "");
        assert_eq!(r.json_block_count, 0);

    // ── RuntimeEvent ──

    #[test]
    fn terminal_event_detection() {
        assert!(RuntimeEvent::Completed.is_terminal());
        assert!(!RuntimeEvent::StdoutChunk("x".into()).is_terminal());
        assert!(!RuntimeEvent::Progress { message: "".into() }.is_terminal());

        assert!(s.contains("[json]"));
        assert!(s.contains("bytes"));

### C. 本RFCの完了条件

1. `JsonExtractor` がフェンスドブロック（```json）、ブレース（`{}`）、
   行JSONの3形式全てを正しく抽出できること（3 tests）
2. JSON抽出失敗時に `ExtractError` に reason + schema + sample が含まれること
3. `RetryExtractor` が指定回数のリトライを実行すること
4. 最終試行で `reformat_only=true` となること
5. 全試行失敗時に最後の `ExtractError` が返されること
6. `RuntimeRequest` の builder パターンが全フィールドで動作すること
7. `RuntimeRequest::to_env_map()` が正しい環境変数を生成すること
8. `RuntimeSession::cancel()` が協力的に動作すること（SIGTERM, force-kill禁止）
9. `RuntimeEvent::Completed` が終端イベントとして認識されること
10. `SessionState` の状態遷移が正しいこと
11. `MarkdownExtractor` がコードブロックを見出しを正しく抽出すること
12. `CompositeExtractor` がフォールバック連鎖を正しく行うこと
13. `TimeoutMonitor` が指定秒数後にフラグをセットすること
14. `ExtractError` が `std::error::Error` トレイトを実装すること
15. `cargo test -p conver-runtime` が全テストパスすること

    Claude Code adapter の各設計判断と矛盾しないこと
