# RFC_004: 永続化ストレージ（conver-storage）

## Abstract

本RFCは、`conver` オーケストレータの永続化層 `conver-storage` crate の設計を
規定する。本crateはファイルベースの永続化バックエンドを提供し、`StorageBackend`
trait（conver-core定義）の実装として `FileBackend` を、`CrudStore` traitの実装
としてファイル操作全般を提供する。全書き込みは `write-temp → fsync → rename` の
atomicパターンに従い、クラッシュ耐性を保証する。改竄検出は SHA-256 ハッシュと
`TamperDetector` により自動検証される。

親RFC: [RFC_ROOT.md](crates/conver/RFC_ROOT.md)（conver: 決定論的 Rust オーケストレータ）
crate 実装先: `crates/conver/rfc-004-storage/`
結合先: `conver-core` が本crateの `StorageBackend` 実装を利用する。

```text
crates/
  conver-core/      # RFC_002 — StorageBackend trait を定義（依存性逆転）
  conver-storage/   ← 本RFCの実装範囲 — StorageBackend を実装
```

SQLite は使用しない。ファイルベースのみ。この判断は Q1 で確定した設計上の決定である。

## Motivation

conver の全状態（RFC_TREE.json / Status.json / DesignTree.json / Tickets.json /
round_log.jsonl / OMISSIONS-<N>.json / .conver/manifest.json / .conver/malfeasance.json）
はファイルシステム上に保存される。本crateは以下の責務を負う：

1. **Atomic書き込み**: 全書き込みは `write-temp → fsync → rename` のパターンに
   従い、書き込み途中のクラッシュでファイルが破損しないことを保証する。
2. **一貫性保証**: 複数ファイルの更新は全か無かのトランザクション性を持つ。
3. **改竄検出**: SHA-256 ハッシュによるファイル改竄の自動検出と検証。
4. **append-only ログ**: `round_log.jsonl` への追記専用書き込み。
5. **CRUD抽象化**: 全ファイル操作を `CrudStore` traitで統一し、上位層が
   ファイル形式を意識せずにデータ操作できるようにする。
6. **マニフェスト管理**: インストールマニフェストの読み書きとハッシュ検証。
7. **チェックポイント永続化**: ワークフロー状態のスナップショット保存と復元。

```rust
// 目標とする使用イメージ（conver-core からの呼出し）
let mut store = FileBackend::new(workspace_root);

// 書き込み
store.write_json("Status.json", &status)?;
store.write_json("DesignTree.json", &design_tree)?;
store.commit_checkpoint()?;

// 読み取り
let stored: StatusRecord = store.read_json("Status.json")?;

// 改竄検証
let report = TamperDetector::verify_all(&rfc_nodes, &store)?;
```

### 2. StorageBackend trait

`conver-core` で定義される StorageBackend trait。本crateはこれを実装する。

```rust
// conver-storage/src/backend.rs
use crate::error::StorageError;
use crate::atomic::AtomicWriter;
use crate::path::PathResolver;
use serde::{Serialize, Deserialize};
use std::path::{Path, PathBuf};

/// ストレージバックエンドの抽象化。
///
/// このtraitは `conver-core` で定義され、本crateが実装する。
pub trait StorageBackend {
    /// ファイルを読み込み、指定された型にdeserializeする。
    fn read_json<T: DeserializeOwned>(&self, path: &str) -> Result<T, StorageError>;

    /// 指定された型をserializeし、ファイルに書き込む。
    fn write_json<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError>;

    /// ファイルの存在確認。
    fn exists(&self, path: &str) -> bool;

    /// ファイルの削除。
    fn remove(&mut self, path: &str) -> Result<(), StorageError>;

    /// ファイルの内容を文字列として読み込む。
    fn read_to_string(&self, path: &str) -> Result<String, StorageError>;

    /// ファイルにバイト列を追記する（append-only）。
    fn append(&mut self, path: &str, data: &[u8]) -> Result<(), StorageError>;

    /// ルートディレクトリ以下の全ファイルを一覧する。
    fn all_files(&self, extension: Option<&str>) -> Result<Vec<PathBuf>, StorageError>;

    /// チェックポイントをコミットする。
    fn commit_checkpoint(&mut self) -> Result<(), StorageError>;

    /// 最後のチェックポイントまでロールバックする。
    fn rollback_to_checkpoint(&mut self) -> Result<(), StorageError>;

    /// ベースパスを返す。
    fn base_path(&self) -> &Path;
}
```

#### FileBackend 実装

```rust
/// ファイルベースの `StorageBackend` 実装。
///
/// 全パスは `base_path` からの相対として解決される。
/// 書き込みは `AtomicWriter` を介して atomic に行われる。
pub struct FileBackend {
    base_path: PathBuf,
    atomic_writer: AtomicWriter,
}

impl FileBackend {
    /// ベースパスを指定して FileBackend を生成する。
    ///
    /// `base_path` が存在しない場合は作成される。
    pub fn new(base_path: impl Into<PathBuf>) -> Result<Self, StorageError> {
        let base_path: PathBuf = base_path.into();
        std::fs::create_dir_all(&base_path)?;
        Ok(Self {
            base_path: base_path.canonicalize()?,
            atomic_writer: AtomicWriter::new(),
        })
    }

    /// 相対パスを絶対パスに解決する。
    fn resolve(&self, path: &str) -> PathBuf {
        self.base_path.join(path)
    }
}

impl StorageBackend for FileBackend {
    fn read_json<T: DeserializeOwned>(&self, path: &str) -> Result<T, StorageError> {
        let full_path = self.resolve(path);
        if !full_path.exists() {
            return Err(StorageError::NotFound(path.to_string()));
        }
        let content = std::fs::read_to_string(&full_path)?;
        serde_json::from_str(&content).map_err(|e| {
            StorageError::Deserialize(path.to_string(), e)
        })
    }

    fn write_json<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError> {
        let full_path = self.resolve(path);
        let json = serde_json::to_string_pretty(data)?;
        self.atomic_writer.write(&full_path, json.as_bytes())?;
        Ok(())
    }

    fn exists(&self, path: &str) -> bool {
        self.resolve(path).exists()
    }

    fn remove(&mut self, path: &str) -> Result<(), StorageError> {
        let full_path = self.resolve(path);
        if full_path.exists() {
            std::fs::remove_file(&full_path)?;
        }
        Ok(())
    }

    fn read_to_string(&self, path: &str) -> Result<String, StorageError> {
        let full_path = self.resolve(path);
        Ok(std::fs::read_to_string(&full_path)?)
    }

    fn append(&mut self, path: &str, data: &[u8]) -> Result<(), StorageError> {
        let full_path = self.resolve(path);
        // 追記は atomic ではないが、ファイル破損リスクは低い
        // （最終行の欠落は許容：次の起動時に最終完全行まで読み直す）
        use std::io::Write;
        let mut file = std::fs::OpenOptions::new()
            .create(true)
            .append(true)
            .open(&full_path)?;
        file.write_all(data)?;
        file.sync_all()?; // fsync で耐久性保証
        writeln!(file)?;  // 行区切り
        file.sync_all()?;
        Ok(())
    }

    fn all_files(&self, extension: Option<&str>) -> Result<Vec<PathBuf>, StorageError> {
        let mut files = Vec::new();
        for entry in walkdir::WalkDir::new(&self.base_path)
            .into_iter()
            .filter_entry(|e| !e.file_name().to_str().map_or(false, |s| s.starts_with('.')))
        {
            let entry = entry?;
            if entry.file_type().is_file() {
                if let Some(ext) = extension {
                    if entry.path().extension().map_or(true, |e| e != ext) {
                        continue;
                    }
                }
                // 相対パスに変換
                let relative = entry.path().strip_prefix(&self.base_path)
                    .unwrap_or(entry.path());
                files.push(relative.to_path_buf());
            }
        }
        Ok(files)
    }

    fn commit_checkpoint(&mut self) -> Result<(), StorageError> {
        let checkpoint = CheckpointStore::new(self.base_path.clone());
        checkpoint.commit()
    }

    fn rollback_to_checkpoint(&mut self) -> Result<(), StorageError> {
        let checkpoint = CheckpointStore::new(self.base_path.clone());
        checkpoint.rollback()
    }

    fn base_path(&self) -> &Path {
        &self.base_path
    }
}
```

### 3. AtomicWriter（write-temp → fsync → rename）

全ファイル書き込みの耐久性を保証する。書き込み中にクラッシュが発生しても、
元のファイルは破損しない。

```rust
// conver-storage/src/atomic.rs
use std::path::{Path, PathBuf};
use std::fs;
use std::io::Write;
use crate::error::StorageError;

/// Atomic書き込み保証。
///
/// 書き込みパターン:
/// 1. `<target>.tmp` に内容を書き込む
/// 2. `fsync` でディスクへの書き込み完了を保証
/// 3. `rename` で一時ファイルを目標ファイルに置き換え（atomic operation）
///
/// 書き込み途中のクラッシュでは `.tmp` ファイルのみが破損し、
/// 目標ファイルは変更されない。
pub struct AtomicWriter;

impl AtomicWriter {
    pub fn new() -> Self {
        Self
    }

    /// ファイルをatomicに書き込む。
    ///
    /// # 引数
    /// - `path`: 書き込み先のファイルパス
    /// - `content`: 書き込む内容
    ///
    /// # エラー
    /// - 親ディレクトリが存在しない場合は作成される
    /// - 一時ファイル作成に失敗した場合は Err を返す
    /// - fsync または rename に失敗した場合は .tmp ファイルを
    ///   クリーンアップして Err を返す
    pub fn write(&self, path: &Path, content: &[u8]) -> Result<(), StorageError> {
        // 親ディレクトリの存在確認・作成
        if let Some(parent) = path.parent() {
            fs::create_dir_all(parent)?;
        }

        let tmp_path = path.with_extension("tmp");

        // Step 1: 一時ファイルに書き込み
        let result = self::write_tmp(&tmp_path, content);

        match result {
            Ok(()) => {
                // Step 3: rename（同一ファイルシステム上のatomic操作）
                fs::rename(&tmp_path, path)?;
                // Step 4: 親ディレクトリのfsync（メタデータの耐久性保証）
                if let Some(parent) = path.parent() {
                    let dir = fs::File::open(parent)?;
                    dir.sync_all()?;
                }
                Ok(())
            }
            Err(e) => {
                // 一時ファイルのクリーンアップ
                let _ = fs::remove_file(&tmp_path);
                Err(e)
            }
        }
    }

    /// 同期的に書き込む（テスト用、本番では write を使用）。
    pub fn write_sync(&self, path: &Path, content: &[u8]) -> Result<(), StorageError> {
        fs::write(path, content)?;
        if let Some(parent) = path.parent() {
            let dir = fs::File::open(parent)?;
            dir.sync_all()?;
        }
        Ok(())
    }
}

/// 一時ファイルへの書き込み（Step 1 + Step 2）。
fn write_tmp(path: &Path, content: &[u8]) -> Result<(), StorageError> {
    let mut file = fs::File::create(path)?;

    // Step 1a: 内容を書き込む
    file.write_all(content)?;

    // Step 2: fsync（データ + メタデータをディスクにフラッシュ）
    file.sync_all()?;

    Ok(())
}
```

### 4. CrudStore trait

CRUD操作の統一インターフェース。`FileBackend` の上に実装される。

```rust
// conver-storage/src/crud.rs
use crate::backend::FileBackend;
use crate::error::StorageError;
use serde::{Serialize, Deserialize};
use std::path::PathBuf;

/// CRUD操作の統一インターフェース。
pub trait CrudStore {
    /// 型 `T` のレコードをキーワードで検索する。
    fn search<T: DeserializeOwned>(
        &self, query: &str, paths: &[&str],
    ) -> Result<Vec<(String, T)>, StorageError>;

    /// 指定パスのレコードを1件取得する。
    fn get<T: DeserializeOwned>(&self, path: &str) -> Result<T, StorageError>;

    /// 指定されたextensionの全ファイルを取得する。
    fn all<T: DeserializeOwned>(&self, extension: &str) -> Result<Vec<(String, T)>, StorageError>;

    /// 新規レコードを作成する。
    fn create<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError>;

    /// 既存レコードを更新する。
    fn update<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError>;

    /// レコードを削除する。
    fn delete(&mut self, path: &str) -> Result<(), StorageError>;

    /// 複数レコードを一括更新する。
    fn batch_update<T: Serialize>(
        &mut self, updates: Vec<(String, T)>,
    ) -> Result<(), StorageError>;

    /// 複数レコードを一括削除する。
    fn batch_delete(&mut self, paths: &[&str]) -> Result<(), StorageError>;
}

impl CrudStore for FileBackend {
    fn search<T: DeserializeOwned>(
        &self, _query: &str, paths: &[&str],
    ) -> Result<Vec<(String, T)>, StorageError> {
        let mut results = Vec::new();
        for path in paths {
            if let Ok(data) = self.read_json::<T>(path) {
                results.push((path.to_string(), data));
            }
        }
        Ok(results)
    }

    fn get<T: DeserializeOwned>(&self, path: &str) -> Result<T, StorageError> {
        self.read_json(path)
    }

    fn all<T: DeserializeOwned>(&self, extension: &str) -> Result<Vec<(String, T)>, StorageError> {
        let files = self.all_files(Some(extension))?;
        let mut results = Vec::new();
        for file in files {
            let path_str = file.to_string_lossy().to_string();
            if let Ok(data) = self.read_json::<T>(&path_str) {
                results.push((path_str, data));
            }
        }
        Ok(results)
    }

    fn create<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError> {
        if self.exists(path) {
            return Err(StorageError::AlreadyExists(path.to_string()));
        }
        self.write_json(path, data)
    }

    fn update<T: Serialize>(&mut self, path: &str, data: &T) -> Result<(), StorageError> {
        if !self.exists(path) {
            return Err(StorageError::NotFound(path.to_string()));
        }
        self.write_json(path, data)
    }

    fn delete(&mut self, path: &str) -> Result<(), StorageError> {
        self.remove(path)
    }

    fn batch_update<T: Serialize>(
        &mut self, updates: Vec<(String, T)>,
    ) -> Result<(), StorageError> {
        for (path, data) in updates {
            self.write_json(&path, &data)?;
        }
        Ok(())
    }

    fn batch_delete(&mut self, paths: &[&str]) -> Result<(), StorageError> {
        for path in paths {
            self.remove(path)?;
        }
        Ok(())
    }
}
```

### 5. チェックポイント永続化

ワークフロー状態のスナップショット保存と復元。`commit_checkpoint()` により
現在の全状態ファイル（Status.json / DesignTree.json / RFC_TREE.json）を
チェックポイントディレクトリにコピーする。

```rust
// conver-storage/src/checkpoint.rs
use std::path::{Path, PathBuf};
use std::fs;
use crate::error::StorageError;

/// チェックポイント永続化。
///
/// チェックポイント状態は `.conver/checkpoints/` ディレクトリに保存される。
/// 各チェックポイントは `cp_<N>/` というサブディレクトリに全状態ファイルを
/// コピーする。
///
/// # ファイル構造
/// ```text
/// .conver/checkpoints/
///   cp_0001/
///     Status.json
///     DesignTree.json
///     RFC_TREE.json
///     round_log.jsonl
///   cp_0002/
///     ...
///   latest -> cp_0002     # 最新へのシンボリックリンク
/// ```
pub struct CheckpointStore {
    base_path: PathBuf,
    counter: u64,
}

impl CheckpointStore {
    /// ベースパスを指定して CheckpointStore を生成する。
    pub fn new(base_path: PathBuf) -> Self {
        Self { base_path, counter: 0 }
    }

    /// チェックポイントディレクトリのパスを返す。
    fn cp_dir(&self) -> PathBuf {
        self.base_path.join(".conver/checkpoints")
    }

    /// 次のチェックポイントIDを生成する。
    fn next_id(&mut self) -> String {
        self.counter += 1;
        format!("cp_{:04}", self.counter)
    }

    /// 現在の状態ファイルをチェックポイントとして保存する。
    ///
    /// 保存対象ファイル:
    /// - Status.json
    /// - DesignTree.json
    /// - RFC_TREE.json
    /// - round_log.jsonl（最新のみ）
    ///
    /// チェックポイントは機械的に（LLM呼出しなしで）副作用として実行される。
    pub fn commit(&mut self) -> Result<(), StorageError> {
        let cp_root = self.cp_dir();
        let cp_id = self.next_id();
        let cp_path = cp_root.join(&cp_id);

        // チェックポイントディレクトリを作成
        fs::create_dir_all(&cp_path)?;

        // 保存対象ファイル
        let files = ["Status.json", "DesignTree.json", "RFC_TREE.json"];

        for file in &files {
            let src = self.base_path.join(file);
            if src.exists() {
                let dst = cp_path.join(file);
                fs::copy(&src, &dst)?;
            }
        }

        // round_log.jsonl も保存（存在する場合）
        let log_src = self.base_path.join("round_log.jsonl");
        if log_src.exists() {
            let log_dst = cp_path.join("round_log.jsonl");
            fs::copy(&log_src, &log_dst)?;
        }

        // 最新チェックポイントへのシンボリックリンクを更新
        let latest_link = cp_root.join("latest");
        let _ = fs::remove_file(&latest_link);
        #[cfg(unix)]
        {
            std::os::unix::fs::symlink(&cp_id, &latest_link)?;
        }
        #[cfg(windows)]
        {
            std::os::windows::fs::symlink_dir(&cp_id, &latest_link)?;
        }

        // 古いチェックポイントのクリーンアップ（最大10世代）
        self.cleanup_old(10)?;

        log::info!("Checkpoint committed: {}", cp_id);
        Ok(())
    }

    /// 最後のチェックポイントまでロールバックする。
    ///
    /// 現在の状態ファイルを削除し、チェックポイントから復元する。
    pub fn rollback(&self) -> Result<(), StorageError> {
        let cp_root = self.cp_dir();
        let latest = cp_root.join("latest");

        if !latest.exists() {
            return Err(StorageError::NoCheckpoint);
        }

        // シンボリックリンクの実体を解決
        let cp_id = std::fs::read_link(&latest)?;
        let cp_path = cp_root.join(&cp_id);

        if !cp_path.exists() {
            return Err(StorageError::CheckpointNotFound(cp_id));
        }

        // 保存対象ファイルを復元
        let files = ["Status.json", "DesignTree.json", "RFC_TREE.json"];
        for file in &files {
            let src = cp_path.join(file);
            if src.exists() {
                let dst = self.base_path.join(file);
                fs::copy(&src, &dst)?;
            }
        }

        log::info!("Rolled back to checkpoint: {}", cp_id.display());
        Ok(())
    }

    /// 指定世代数を超えた古いチェックポイントを削除する。
    fn cleanup_old(&self, max_generations: usize) -> Result<(), StorageError> {
        let cp_root = self.cp_dir();
        if !cp_root.exists() {
            return Ok(());
        }

        let mut entries: Vec<_> = fs::read_dir(&cp_root)?
            .filter_map(|e| e.ok())
            .filter(|e| e.file_type().map_or(false, |t| t.is_dir()))
            .collect();

        // 名前でソート（cp_0001, cp_0002, ...）
        entries.sort_by_key(|e| e.file_name());

        // 最大世代数を超えた古いものを削除
        while entries.len() > max_generations {
            if let Some(old) = entries.first() {
                let path = old.path();
                if path.file_name().unwrap_or_default() != "latest" {
                    fs::remove_dir_all(&path)?;
                }
                entries.remove(0);
            }
        }

        Ok(())
    }
}
```

### 6. round_log.jsonl（append-only）

観測ベクトルの時系列を追記専用で保存する。

```rust
// conver-storage/src/round_log.rs
use std::path::{Path, PathBuf};
use std::fs::{self, OpenOptions};
use std::io::Write;
use crate::error::StorageError;

/// 追記専用ログ（round_log.jsonl）。
///
/// JSON Lines形式で各ループの観測ベクトルを保存する。
/// 1行が1つのObservationVector。
/// 追記のみで過去行の変更は行わず、改竄耐性が高い。
///
/// # 改行区切り書式
/// ```text
/// {"r":1,"delta":5.0,"m":2,...}
/// {"r":2,"delta":2.0,"m":1,...}
/// {"r":3,"delta":0.0,"m":0,...}
/// ```
pub struct AppendOnlyLog {
    path: PathBuf,
}

impl AppendOnlyLog {
    /// ログファイルのパスを指定する。
    pub fn new(base_path: &Path) -> Self {
        Self {
            path: base_path.join("round_log.jsonl"),
        }
    }

    /// 1行を追記する。
    ///
    /// 書き込み後に `fsync` を実行し、耐久性を保証する。
    pub fn append(&self, line: &str) -> Result<(), StorageError> {
        let mut file = OpenOptions::new()
            .create(true)
            .append(true)
            .open(&self.path)?;

        writeln!(file, "{}", line)?;
        file.sync_all()?;

        Ok(())
    }

    /// 全行を読み込む。
    pub fn read_all(&self) -> Result<Vec<String>, StorageError> {
        if !self.path.exists() {
            return Ok(Vec::new());
        }

        let content = fs::read_to_string(&self.path)?;
        Ok(content.lines().map(|l| l.to_string()).collect())
    }

    /// 最新の1行を読み込む。
    pub fn read_latest(&self) -> Result<Option<String>, StorageError> {
        let lines = self.read_all()?;
        Ok(lines.last().cloned())
    }

    /// ログの行数を返す（ループ回数と一致）。
    pub fn count(&self) -> Result<usize, StorageError> {
        Ok(self.read_all()?.len())
    }
}

/// ObservationVector を round_log.jsonl に追記する便利関数。
pub fn append_observation<T: serde::Serialize>(
    base_path: &Path, observation: &T,
) -> Result<(), StorageError> {
    let log = AppendOnlyLog::new(base_path);
    let line = serde_json::to_string(observation)?;
    log.append(&line)
}

### 7. 改竄検出（TamperDetector）

SHA-256 ハッシュによるファイル改竄の自動検出。

```rust
// conver-storage/src/tamper.rs
use sha2::{Sha256, Digest};
use std::path::Path;
use std::fs;
use crate::error::StorageError;
use crate::backend::StorageBackend;

/// 改竄検出器。
///
/// SHA-256 ハッシュを各ファイルのノードデータに内蔵し、ファイル内容の
/// 改竄を検出する。RFC_TREE.json 自身のハッシュは `.conver/manifest.json`
/// に保存される。
///
/// # 検出フロー
/// 1. RFC_TREE.json の各ノードから sha256 フィールドを読む
/// 2. 該当ファイルを開いて SHA-256 を計算
/// 3. 保存されているハッシュと比較
/// 4. 不一致があれば violations として報告
/// 5. RFC_TREE.json 自身のハッシュは manifest.json で検証
pub struct TamperDetector;

impl TamperDetector {
    /// 全ファイルのSHA-256ハッシュを検証する。
    ///
    /// # 引数
    /// - `nodes`: RFC_TREE.json のノード一覧（各ノードに sha256 と path を含む）
    /// - `storage`: ファイル読み取り用の StorageBackend
    ///
    /// # 戻り値
    /// - `Ok(Vec<String>)`: 改竄が検出されたファイルパスの一覧（空=改竄なし）
    pub fn verify_all(
        nodes: &[RfcNodeInfo],
        storage: &dyn StorageBackend,
    ) -> Result<Vec<String>, StorageError> {
        let mut violations = Vec::new();

        for node in nodes {
            let file_path = storage.base_path().join(&node.path);

            // . の場合はスキップ（RFC_ROOT.md 自体は manifest.json で検証）
            if node.path == "." {
                continue;
            }

            // RFC_XXX.md と Tickets.json の両方を検証
            for filename in &[format!("RFC_{}.md", node.id), "Tickets.json".to_string()] {
                let target = file_path.join(&filename);
                if !target.exists() {
                    violations.push(format!("{}: missing file", target.display()));
                    continue;
                }

                let content = fs::read(&target).map_err(|e| {
                    StorageError::IoError(format!("{}: {}", target.display(), e))
                })?;

                let actual_hash = hex::encode(Sha256::digest(&content));

                if !node.sha256.is_empty() && actual_hash != node.sha256 {
                    violations.push(format!(
                        "{}: hash mismatch (expected={}, actual={})",
                        target.display(),
                        &node.sha256[..16.min(node.sha256.len())],
                        &actual_hash[..16]
                    ));
                }
            }
        }

        Ok(violations)
    }

    /// 単一ファイルのSHA-256ハッシュを計算する。
    pub fn compute_hash(path: &Path) -> Result<String, StorageError> {
        let content = fs::read(path)?;
        Ok(hex::encode(Sha256::digest(&content)))
    }

    /// RFC_TREE.json 自身のハッシュを manifest.json と照合する。
    pub fn verify_manifest(
        base_path: &Path,
    ) -> Result<bool, StorageError> {
        let manifest_path = base_path.join(".conver/manifest.json");
        let rfc_tree_path = base_path.join("RFC_TREE.json");

        if !manifest_path.exists() || !rfc_tree_path.exists() {
            return Ok(false);
        }

        let manifest_content = fs::read_to_string(&manifest_path)?;
        let manifest: serde_json::Value = serde_json::from_str(&manifest_content)?;

        let expected_hash = manifest["rfc_tree_hash"]
            .as_str()
            .ok_or_else(|| StorageError::Deserialize(
                ".conver/manifest.json".into(),
                serde::de::Error::custom("rfc_tree_hash not found"),
            ))?;

        let actual_hash = Self::compute_hash(&rfc_tree_path)?;

        Ok(actual_hash == expected_hash)
    }

    /// ハッシュを更新する（AI修正案提示後に呼ばれる）。
    pub fn refresh_hash(
        node: &mut RfcNodeInfo,
        base_path: &Path,
        storage: &mut dyn StorageBackend,
    ) -> Result<(), StorageError> {
        let file_path = base_path.join(&node.path);
        let rfc_file = file_path.join(format!("RFC_{}.md", node.id));
        if rfc_file.exists() {
            node.sha256 = Self::compute_hash(&rfc_file)?;
        }
        Ok(())
    }
}

/// RFCノードのパスとハッシュ情報（RFC_TREE.jsonのノードに対応）。
#[derive(Debug, Clone)]
pub struct RfcNodeInfo {
    pub id: String,
    pub path: String,
    pub sha256: String,
}

    /// マニフェストを読み込む。

        let path = self.base_path.join(".conver/manifest.json");
        if !path.exists() {
            return Ok(None);
        }
        let content = fs::read_to_string(&path)?;
        let manifest: Manifest = serde_json::from_str(&content)?;
        Ok(Some(manifest))
    }

            fs::create_dir_all(parent)?;
        }
        let json = serde_json::to_string_pretty(manifest)?;
        fs::write(&path, json)?;
        Ok(())
    }

    /// マニフェストに RFC_TREE.json のハッシュを保存する。
    pub fn store_rfc_tree_hash(&self, hash: &str) -> Result<(), StorageError> {
        let mut manifest = self.read()?.unwrap_or(Manifest {
            version: 1,
            installed_by: env!("CARGO_PKG_NAME").to_string(),
            updated_at: chrono::Utc::now().to_rfc3339(),
            assets: Vec::new(),
            rfc_tree_hash: None,
        });
        manifest.rfc_tree_hash = Some(hash.to_string());
        self.write(&manifest)
    }

    /// アセットのバージョン比較を行い、更新が必要か判定する。
    pub fn should_update(
        installed: &ManifestAsset,
        embedded_sha256: &str,
    ) -> bool {
        installed.sha256 != embedded_sha256
    }

// conver-storage/src/path.rs
use std::path::{Path, PathBuf};

/// ルート相対パス解決。
///
/// RFC_TREE.json の path フィールド（"." や "rfc-001-cli" 等）を
/// ファイルシステム上の絶対パスに解決する。
pub struct PathResolver {
    root: PathBuf,
}

impl PathResolver {
    pub fn new(root: PathBuf) -> Self {
        Self { root }
    }

    /// RFC_TREE.json の path を絶対パスに解決する。
    ///
    /// # 例
    /// - `"."` → `/path/to/crates/conver/`
    /// - `"rfc-001-cli"` → `/path/to/crates/conver/rfc-001-cli/`
    pub fn resolve(&self, rfc_path: &str) -> PathBuf {
        if rfc_path == "." {
            self.root.clone()
        } else {
            self.root.join(rfc_path)
        }
    }

    /// 指定された RFC ノードの RFC_XXX.md へのパスを返す。
    pub fn rfc_file(&self, node_id: &str, rfc_path: &str) -> PathBuf {
        let dir = self.resolve(rfc_path);
        dir.join(format!("RFC_{}.md", node_id))
    }

    /// 指定された RFC ノードの Tickets.json へのパスを返す。
    pub fn tickets_file(&self, rfc_path: &str) -> PathBuf {
        let dir = self.resolve(rfc_path);
        dir.join("Tickets.json")
    }

    /// ルートディレクトリを返す。
    pub fn root(&self) -> &Path {
        &self.root
    }
}

### E. 設計資料（crates/conver/docs/）の利活用

`crates/conver/docs/` ディレクトリには本RFCおよび全子RFCの設計に先立って
収集・生成された設計資料が格納されている。これらの資料は以下のように利活用する。

#### 構成

| パス | 内容 | 本RFCとの関係 |
|------|------|-------------|
| `docs/conver-rfc-design-ja.md` | オリジナルRFC草案 | 本RFCの前身。grillセッションのインプットとして使用された |
| `docs/rfc_tree_self_converging_development_design.md` | 完全版設計記述 | 自己収束開発サイクルの理論的背景。数学的定式化の原典 |
| `docs/EVALUATION.md` | 専門家による設計評価 | 本RFCで解決された6つの指摘を含む評価レポート |
| `docs/claude/commands/*.md` | 7種のスラッシュコマンド定義 | `conver init` で配布されるコマンドの参考実装。互換性検証に使用 |
| `docs/claude/scripts/grill-me-for-rfc/*.js` | 9種のgrill用スクリプト | conver-cli の各機能のリファレンス実装。Rust移植の検証用 |
| `docs/claude/scripts/tickets/*.js` | 17種のチケット管理スクリプト | conver-core のチケット操作のリファレンス実装 |
| `docs/claude/scripts/tickets/review/*.js` | 3種のレビュー・品質スクリプト | conver-validation の品質ゲートのリファレンス実装 |
| `docs/claude/scripts/lib/*.js` | 4種の共通ライブラリ | 各crateの共通ロジックの参考実装 |

#### 利活用方法

1. **互換性検証**: `cargo run --bin test-run` の出力と従来スクリプトの実行結果を
   比較することで、Rust移植の正しさを機械的に検証できる。
2. **リファレンス実装**: 各Node.jsスクリプトは対応するRustモジュールの
   リファレンス実装として機能する。仕様の曖昧な部分は従来スクリプトの
   動作を確認することで補完できる。
3. **回帰テスト**: 従来スクリプトのテストケースをRustのテストコードとして
   再利用することで、機能退行を防止する。
4. **ドキュメント原典**: `docs/rfc_tree_self_converging_development_design.md` は
   数学的定式化の原典であり、RFC_006の理論的根拠として参照する。

### B. 書き込みパターン図解

```text
正常系:
  write_json("Status.json", data)
    → Status.json.tmp に書き込み（Step 1）
    → fsync（Step 2）
    → rename Status.json.tmp → Status.json（Step 3: atomic）
    → 親ディレクトリの fsync（Step 4）

クラッシュ後:
  Status.json.tmp が残っていても Status.json は無事
  次回起動時に .tmp ファイルをクリーンアップ
```
