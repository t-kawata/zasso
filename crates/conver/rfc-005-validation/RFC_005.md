# RFC_005: プロジェクション・検証（conver-projection + conver-validation）

## Abstract

本RFCは、`conver` オーケストレータのプロジェクション層 `conver-projection` と
検証層 `conver-validation` の2つのcrateの設計を規定する。

`conver-projection` は canonical state（JSON）から人間可読なMarkdown /
JSON artifact を生成する。具体的には CheckList.md、OMISSIONS.md（人間用）、
収束レポート（端末表示）、および各種JSONファイルのprojectionを担う。

`conver-validation` は4種の検証ゲート（スキーマ検証 / 質問フォーマット検証 /
品質ゲート / DAG検証）を提供する。全ゲートは常時必須であり、全状態変更操作の
後に自動実行される。

親RFC: [RFC_ROOT.md](crates/conver/RFC_ROOT.md)（conver: 決定論的 Rust オーケストレータ）
crate 実装先: `crates/conver/rfc-005-validation/` および `crates/conver/rfc-005-validation/`
結合先: `conver-core` が両crateを利用する。

```text
crates/
  conver-core/          # RFC_002 — 本crateの検証ゲートを呼び出す
  conver-projection/    ← 本RFCの実装範囲（前半）
  conver-validation/    ← 本RFCの実装範囲（後半）
```

## Motivation

conver の全データは canonical JSON（Status.json / DesignTree.json / RFC_TREE.json /
Tickets.json / OMISSIONS-<N>.json / round_log.jsonl）として保存される。しかし、
人間はこれらのJSONを直接読むのではなく、Markdownや端末表示で内容を確認する。
projection層はこの変換を担う。

また、conver の全操作は検証ゲートを通過しなければならない。検証ゲートは
データの整合性・形式・完成条件を機械的にチェックし、違反を検出した場合は
操作を失敗させる。validation層はこれらのゲートを提供する。

```rust
// 目標とする使用イメージ
// -- Projection --
let report = ConvergenceReporter::new(&tree, &omissions, &score);
println!("{}", report.format_text(&settings.deviation));

let checklist = ChecklistGenerator::generate(&design_tree);
storage.write_string("CheckList.md", &checklist)?;

// -- Validation --
let validator = QuestionFormatValidator;
validator.validate(question)?; // 失敗時は ValidationErrors

let gate = QualityGate::new(&design_tree, &rfc_text);
gate.validate()?; // DesignTree 全 resolved + 禁止表現 0 件
```

#### 1.2 ChecklistGenerator（CheckList.md 生成）

DesignTree の全ノードからチェックリストを生成する。

```rust
// conver-projection/src/checklist.rs
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;

/// チェックリスト生成器。
pub struct ChecklistGenerator;

impl ChecklistGenerator {
    /// DesignTree から CheckList.md を生成する。
    ///
    /// 出力形式（Markdown）:
    /// ```markdown
    /// # RFC 要件チェックリスト
    ///
    /// ## §1 セクション名
    /// - [ ] セクション全体が完全に記述されている
    /// - [ ] コードスニペットが含まれている
    /// - [ ] TBD / TODO / プレースホルダが含まれていないこと
    ///
    /// ### §1.1 子ノード名
    /// - [ ] 子ノードのtitleが設計として完全に記述されている
    /// - [ ] コードスニペットが含まれている
    /// - [ ] TBD / TODO / プレースホルダが含まれていないこと
    /// ```
    pub fn generate(nodes: &[DesignTreeNode]) -> String {
        let mut md = String::new();
        md.push_str("# RFC 要件チェックリスト\n\n");
        md.push_str("> 自動生成: DesignTree から機械的に生成されたチェックリスト。\n\n");
        md.push_str("---\n\n");

        let mut section_counter = 0u32;

        for (i, node) in nodes.iter().enumerate() {
            section_counter += 1;
            let status_icon = if node.is_leaf() { "✅" } else { "" };
            md.push_str(&format!("## §{i} {} {status_icon}\n\n", node.title));
            md.push_str("- [ ] セクション全体が完全に記述されている\n");
            md.push_str("- [ ] コードスニペットが含まれている\n");
            md.push_str("- [ ] TBD / TODO / プレースホルダが含まれていないこと\n\n");

            let mut sub_counter = 0u32;
            for child in &node.children {
                sub_counter += 1;
                md.push_str(&format!(
                    "### §{section_counter}.{sub_counter} {} ✅\n\n",
                    child.title
                ));
                md.push_str(&format!(
                    "- [ ] **{}** が設計として完全に記述されている\n",
                    child.title
                ));
                md.push_str("- [ ] コードスニペットが含まれている\n");
                md.push_str("- [ ] TBD / TODO / プレースホルダが含まれていないこと\n\n");
            }

            md.push_str("---\n\n");
        }

        md
    }

    /// チェックリストの全項目が完了しているか検証する。
    ///
    /// 実際のチェックは人間が行う。このメソッドは機械的に確認可能な
    /// フォーマットの検証のみ行う。
    pub fn validate_format(checklist: &str) -> Result<(), ChecklistError> {
        if !checklist.contains("# RFC 要件チェックリスト") {
            return Err(ChecklistError::MissingHeader);
        }
        // 各セクションにチェック項目があること
        let sections: Vec<_> = checklist.matches("## §").collect();
        if sections.is_empty() {
            return Err(ChecklistError::NoSections);
        }
        Ok(())
    }
}

#[derive(Debug)]
pub enum ChecklistError {
    MissingHeader,
    NoSections,
}

impl std::fmt::Display for ChecklistError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            ChecklistError::MissingHeader => write!(f, "CheckList.md: ヘッダー行がありません"),
            ChecklistError::NoSections => write!(f, "CheckList.md: セクションがありません"),
        }
    }
}

/// DesignTree のノード（projection用の軽量構造）。
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct DesignTreeNode {
    pub id: String,
    pub title: String,
    pub children: Vec<DesignTreeNode>,
    pub status: String,
}

impl DesignTreeNode {
    pub fn is_leaf(&self) -> bool {
        self.children.is_empty()
    }
}

```rust
// conver-projection/src/omissions_md.rs

/// Omissions の Markdown レポート生成器。
pub struct OmissionsReport;

impl OmissionsReport {
    /// OMISSIONS-<N>.json を人間可読な Markdown に変換する。
    pub fn generate(omissions: &OmissionsData) -> String {
        let mut md = String::new();
        md.push_str(&format!("# 乖離レポート（Round {round}）\n\n", round = omissions.round));
        md.push_str(&format!(
            "検出日時: {detected}\n\n", detected = omissions.detected_at
        ));

        if omissions.omissions.is_empty() {
            md.push_str("**乖離なし（Δ = 0）** 収束完了。\n");
            return md;
        }

        // 分類ごとに集計
        let mut by_kind: std::collections::BTreeMap<&str, Vec<&OmissionEntry>> =
            std::collections::BTreeMap::new();
        for entry in &omissions.omissions {
            by_kind.entry(&entry.kind).or_default().push(entry);
        }

        // サマリ
        md.push_str("## サマリ\n\n");
        md.push_str("| 分類 | 件数 |\n|------|------|\n");
        for (kind, entries) in &by_kind {
            md.push_str(&format!("| {} | {} |\n", kind, entries.len()));
        }
        md.push('\n');

        // 詳細
        md.push_str("## 詳細\n\n");
        for (kind, entries) in &by_kind {
            md.push_str(&format!("### {kind}\n\n"));
            for entry in entries {
                md.push_str(&format!(
                    "- **{node}**（チケット: {ticket}）: {desc}\n",
                    node = entry.rfc_node_id,
                    ticket = entry.ticket_id.as_deref().unwrap_or("N/A"),
                    desc = entry.description,
                ));
                if let Some(ref loc) = entry.code_location {
                    md.push_str(&format!("  - コード位置: `{loc}`\n"));
                }
                md.push_str(&format!("  - 重要度: **{sev}**\n", sev = entry.severity));
            }
        }

        md
    }
}

/// omissionsデータの軽量構造体（projection用）。
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct OmissionsData {
    pub round: u32,
    pub detected_at: String,
    pub omissions: Vec<OmissionEntry>,
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct OmissionEntry {
    pub kind: String,
    pub rfc_node_id: String,
    pub ticket_id: Option<String>,
    pub description: String,
    pub code_location: Option<String>,
    pub severity: String,
}

#### 1.4 ConvergenceReporter（収束レポート）

`conver status` コマンドの表示内容を生成する。

```rust
// conver-projection/src/report.rs

/// 収束レポート（`conver status` で表示される内容）。
///
/// 出力例:
/// ```text
/// [conver] Round 3 — Convergence Report
/// ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
///  Δ = 5  (M:2  C:1  U:0  X:2)
///
///  ▼ Per-RFC-node deviation vector (bar: 50 segments)
///    rfc-conver      Δ=0  ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■ 100%
///    rfc-module-a    Δ=2  ■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■□□□□□□□□□□□□  70%
///    rfc-module-b    Δ=3  ■■■■■■■■■■■■■■■■■■■■■■■■■□□□□□□□□□□□□□□□□□□□□□□□□  50%
///
///  Status: CONVERGING (3 rounds / limit 3)
/// ```
pub struct ConvergenceReporter {
    round: u32,
    max_rounds: u32,
    delta: f64,
    components: DeviationComponentsData,
    per_node: Vec<(String, f64)>,
    state: String,
    visualization_bars: u32,
}

#[derive(Debug, Clone)]
pub struct DeviationComponentsData {
    pub m: usize,
    pub c: usize,
    pub u: usize,
    pub x: usize,
}

impl ConvergenceReporter {
    pub fn new(
        round: u32,
        max_rounds: u32,
        delta: f64,
        components: DeviationComponentsData,
        per_node: Vec<(String, f64)>,
        state: &str,
        visualization_bars: u32,
    ) -> Self {
        Self {
            round,
            max_rounds,
            delta,
            components,
            per_node,
            state: state.to_string(),
            visualization_bars,
        }
    }

    /// テキストレポートを生成する。
    ///
    /// 各RFCノードの充足度バーは `visualization_bars` で指定された
    /// 分割数（デフォルト50 = 2%単位）で表示される。
    pub fn format_text(&self) -> String {
        let mut output = String::new();
        let bar_width = self.visualization_bars as usize;

        output.push_str(&format!(
            "[conver] Round {} — Convergence Report\n",
            self.round
        ));
        output.push_str(&"━".repeat(50));
        output.push('\n');

        // Δ サマリ
        output.push_str(&format!(
            " Δ = {}  (M:{}  C:{}  U:{}  X:{})\n\n",
            self.delta,
            self.components.m,
            self.components.c,
            self.components.u,
            self.components.x,
        ));

        // ノード別充足度バー
        output.push_str(&format!(
            " ▼ Per-RFC-node deviation vector (bar: {} segments)\n",
            bar_width
        ));

        // 最大Δを求めて正規化
        let max_delta = self.per_node.iter()
            .map(|(_, d)| *d)
            .fold(0.0_f64, f64::max)
            .max(1.0); // ゼロ除算防止

        for (node_id, node_delta) in &self.per_node {
            let ratio = 1.0 - (node_delta / max_delta);
            let filled = (ratio * bar_width as f64).round() as usize;
            let filled = filled.clamp(0, bar_width);
            let empty = bar_width - filled;

            let bar: String = std::iter::repeat('■').take(filled)
                .chain(std::iter::repeat('□').take(empty))
                .collect();

            let percent = (ratio * 100.0).round();

            output.push_str(&format!(
                "   {:<15} Δ={:<5} {} {:>3.0}%\n",
                node_id,
                node_delta,
                bar,
                percent,
            ));
        }

        // ステータス
        output.push('\n');
        output.push_str(&format!(
            " Status: {} ({} rounds / limit {})\n",
            self.state, self.round, self.max_rounds,
        ));

        output
    }

    /// プレーン（装飾なし）レポートを生成する。
    pub fn format_plain(&self) -> String {
        let mut output = String::new();
        output.push_str(&format!("Round: {}\n", self.round));
        output.push_str(&format!("State: {}\n", self.state));
        output.push_str(&format!("Δ: {}\n", self.delta));
        output.push_str(&format!(
            "  M:{} C:{} U:{} X:{}\n",
            self.components.m,
            self.components.c,
            self.components.u,
            self.components.x,
        ));
        output
    }
}
```

/// Markdown共通テンプレート。
pub struct MarkdownTemplate;

impl MarkdownTemplate {
    /// コードブロックを生成する。
    pub fn code_block(language: &str, content: &str) -> String {
        format!("```{language}\n{content}\n```\n")
    }

    /// テーブルを生成する。
    pub fn table(headers: &[&str], rows: &[Vec<&str>]) -> String {
        let mut md = String::new();
        // ヘッダー
        md.push_str(&format!(
            "| {} |\n",
            headers.iter().map(|h| format!(" {}", h)).collect::<Vec<_>>().join(" |")
        ));
        md.push_str(&format!(
            "|{}|\n",
            headers.iter().map(|_| " --- ").collect::<Vec<_>>().join("|")
        ));
        // 行
        for row in rows {
            md.push_str(&format!(
                "| {} |\n",
                row.iter().map(|c| format!(" {}", c)).collect::<Vec<_>>().join(" |")
            ));
        }
        md
    }

    /// 水平線。
    pub fn horizontal_rule() -> &'static str {
        "\n---\n"
    }
}

#### 2.2 Validator trait（全検証ゲートの統一インターフェース）

```rust
// conver-validation/src/lib.rs
use std::fmt::Debug;

/// 全検証ゲートの統一インターフェース。
pub trait Validator<T: ?Sized> {
    /// 対象を検証する。エラーがある場合は `ValidationErrors` を返す。
    fn validate(&self, target: &T) -> Result<(), ValidationErrors>;
}

/// 検証エラーの集合。
#[derive(Debug, Clone)]
pub struct ValidationErrors {
    pub errors: Vec<String>,
}

impl ValidationErrors {
    pub fn new() -> Self {
        Self { errors: Vec::new() }
    }

    pub fn add(&mut self, msg: impl Into<String>) {
        self.errors.push(msg.into());
    }

    pub fn is_empty(&self) -> bool {
        self.errors.is_empty()
    }

    pub fn merge(&mut self, other: ValidationErrors) {
        self.errors.extend(other.errors);
    }
}

impl std::fmt::Display for ValidationErrors {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        for err in &self.errors {
            writeln!(f, "- {err}")?;
        }
        Ok(())
    }
}

impl<E: Into<String>> From<Vec<E>> for ValidationErrors {
    fn from(errors: Vec<E>) -> Self {
        Self {
            errors: errors.into_iter().map(Into::into).collect(),
        }
    }
}

#### 2.3 SchemaValidator（スキーマ検証ゲート）

Status.json / DesignTree.json / CheckList.md の構造を検証する。

```rust
// conver-validation/src/schema.rs
use crate::{Validator, ValidationErrors};
use serde_json::Value;

/// スキーマ検証ゲート。
///
/// 検証対象: Status.json, DesignTree.json, CheckList.md
///
/// 検証ルール（Status.json）:
/// - `state` フィールドが有効な WorkflowState 値である
/// - `round` フィールドが数値かつ0以上である
///
/// 検証ルール（DesignTree.json）:
/// - `version` が数値かつ1以上である
/// - `updatedAt` がパース可能な日付である
/// - 全ノードのIDが一意である
/// - `status` が "open" または "resolved" である
/// - `children` が配列である
///
/// 検証ルール（CheckList.md）:
/// - "RFC 要件チェックリスト" のヘッダーが存在する
/// - 1つ以上のセクション（## §）が存在する
pub struct SchemaValidator;

impl SchemaValidator {
    pub fn new() -> Self {
        Self
    }
}

impl Validator<str> for SchemaValidator {
    fn validate(&self, target: &str) -> Result<(), ValidationErrors> {
        // ファイル名から検証方法を選択
        // （呼出し元がファイル名を識別できる場合は個別メソッドを使用）
        let mut errors = ValidationErrors::new();

        // Status.json の検証（`state` フィールドを含む場合）
        if let Ok(json) = serde_json::from_str::<Value>(target) {
            if let Some(state) = json.get("state").and_then(|v| v.as_str()) {
                let valid_states = [
                    "Grilling", "ChecklistPending", "ChecklistApproved",
                    "Writing", "Reviewing", "Done",
                ];
                if !valid_states.contains(&state) {
                    errors.add(format!("Status.json: 不明な状態 '{state}'"));
                }
            }
            if let Some(round) = json.get("round").and_then(|v| v.as_u64()) {
                // round は 0 以上
            }
        }

        Ok(())
    }
}

/// DesignTree 専用バリデータ。
pub struct DesignTreeValidator;

impl DesignTreeValidator {
    pub fn new() -> Self {
        Self
    }

    pub fn validate_json(&self, json: &Value) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        // version
        let version = json.get("version").and_then(|v| v.as_u64());
        if version.is_none() || version.unwrap() < 1 {
            errors.add("DesignTree.json: version は1以上である必要があります");
        }

        // updatedAt
        let updated = json.get("updatedAt")
            .or_else(|| json.get("updated_at"))
            .and_then(|v| v.as_str());
        if updated.is_none() {
            errors.add("DesignTree.json: updatedAt が必要です");
        }

        // nodes
        let nodes = json.get("nodes").and_then(|v| v.as_array());
        if nodes.is_none() {
            errors.add("DesignTree.json: nodes 配列が必要です");
            return Err(errors);
        }
        let nodes = nodes.unwrap();

        // ノードIDの一意性
        let mut ids = std::collections::HashSet::new();
        for (i, node) in nodes.iter().enumerate() {
            if let Some(id) = node.get("id").and_then(|v| v.as_str()) {
                if !ids.insert(id) {
                    errors.add(format!("DesignTree.json: 重複ID '{}'", id));
                }
            } else {
                errors.add(format!("DesignTree.json: nodes[{}] に id がありません", i));
            }

            // status
            let status = node.get("status").and_then(|v| v.as_str());
            match status {
                Some("open") | Some("resolved") => {}
                Some(s) => errors.add(format!("ノード '{}': 不明な status '{}'", node.get("id").and_then(|v| v.as_str()).unwrap_or("?"), s)),
                None => errors.add(format!("nodes[{}]: status が必要", i)),
            }

            // children（オプショナルだが配列であるべき）
            if let Some(children) = node.get("children") {
                if !children.is_array() {
                    errors.add(format!("nodes[{}]: children は配列である必要があります", i));
                }
            }
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }
}

/// CheckList 専用バリデータ。
pub struct ChecklistValidator;

impl ChecklistValidator {
    pub fn new() -> Self {
        Self
    }

    pub fn validate_markdown(&self, md: &str) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        if !md.contains("# RFC 要件チェックリスト") {
            errors.add("CheckList.md: '# RFC 要件チェックリスト' ヘッダーが必要です");
        }

        let section_count = md.matches("## §").count();
        if section_count == 0 {
            errors.add("CheckList.md: セクション（## §）が1つもありません");
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }
}

///
/// 検証ルール:
/// 0. 質問ID（Q<番号>）が含まれている
/// 1. 理由・背景・トレードオフが含まれている
/// 2. Yes/No または ABC 選択肢で回答可能である
/// 3. 自由記述を求める表現が含まれていない
/// 4. 選択肢は改行で区切られたリスト形式である
/// 5. AIが1つを選んだ推奨＋理由が含まれている
pub struct QuestionFormatValidator;

impl QuestionFormatValidator {
    pub fn new() -> Self {
        Self
    }
}

impl Validator<str> for QuestionFormatValidator {
    fn validate(&self, question: &str) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        // ルール0: 質問ID
        let has_id = regex_check(question, r"\bQ\d+\b");
        if !has_id {
            errors.add("質問ID（Q<番号>）が含まれていません");
        }

        // ルール1: 理由・背景
        let reasoning_keywords = [
            "理由", "ため", "だから", "なぜ", "なので",
            "提案", "比較", "メリット", "デメリット",
            "一方", "対して", "trade-off",
            "コスト", "影響", "懸念",
            "スケーラビリティ", "保守性",
        ];
        let has_reasoning = reasoning_keywords.iter().any(|k| question.contains(k));
        if !has_reasoning {
            errors.add("理由・背景・トレードオフの説明が不足しています");
        }

        // ルール2: A/B/C 選択肢
        let has_choice = [
            "A)", "B)", "C)", "(A)", "(B)", "(C)",
            "A）", "B）", "C）",
            "Yes", "No", "賛成", "反対",
        ].iter().any(|c| question.contains(c));
        if !has_choice {
            errors.add("Yes/No または A/B/C の選択肢が必要です");
        }

        // ルール3: 自由記述禁止
        let open_ended = [
            "どう思いますか", "どう考えますか", "自由にお書きください",
            "教えてください", "任意",
        ];
        if open_ended.iter().any(|k| question.contains(k)) && !has_choice {
            errors.add("自由記述を求める表現が含まれています");
        }

        // ルール4: 選択肢は改行リスト
        let lines: Vec<&str> = question.lines().collect();
        for line in &lines {
            let inline_count = [
                line.contains("A)"), line.contains("B)"), line.contains("C)"),
            ].iter().filter(|&&b| b).count();
            if inline_count >= 2 {
                errors.add("複数の選択肢が同じ行に並んでいます");
                break;
            }
        }

        // ルール5: 推奨＋理由
        let last_choice_line = lines.iter().rposition(|l| {
            l.contains("A)") || l.contains("B)") || l.contains("C)")
        });
        if let Some(pos) = last_choice_line {
            let after = lines[pos + 1..].join("\n");
            let has_recommendation = [
                "おすすめ", "推奨", "推す", "推薦",
                "recommend", "suggest",
            ].iter().any(|k| after.contains(k));
            if !has_recommendation {
                errors.add("選択肢列挙後にAIの推奨＋理由が必要です");
            }
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }
}

/// 簡易正規表現チェック（外部crateに依存しない）。
fn regex_check(text: &str, pattern: &str) -> bool {
    // Q<digit>+ の簡易チェック
    if pattern == r"\bQ\d+\b" {
        return text.chars()
            .collect::<Vec<_>>()
            .windows(2)
            .any(|w| w[0] == 'Q' && w[1].is_ascii_digit());
    }
    false
}

#### 2.5 QualityGate（品質ゲート）

完全性の最終チェック。RFC完了条件の機械的検証。

```rust
// conver-validation/src/quality.rs
use crate::{Validator, ValidationErrors};

/// 品質ゲート。
///
/// 完了条件:
/// 1. DesignTree の全ノードが resolved（open-count = 0）
/// 2. CheckList の全項目がマーク済み
/// 3. RFC_ROOT.md 本文に禁止表現（TBD/TODO/プレースホルダ）が0件
/// 4. 乖離関数 Δ = 0（OMISSIONS が空）
/// 5. 全ファイルのSHA-256ハッシュが一致
/// 6. 未解決 STUB がゼロ
pub struct QualityGate;

impl QualityGate {
    pub fn new() -> Self {
        Self
    }

    /// 完全性を検証する。
    pub fn validate_completion(
        &self,
        design_tree_open_count: usize,
        rfc_text: &str,
        delta: f64,
        stub_count: usize,
    ) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        // 条件1: DesignTree 全 resolved
        if design_tree_open_count > 0 {
            errors.add(format!(
                "DesignTree に未解決ノードが {} 件あります",
                design_tree_open_count
            ));
        }

        // 条件3: RFC本文に禁止表現
        let forbidden = ["TBD", "TODO"];
        for &word in &forbidden {
            if rfc_text.contains(word) {
                errors.add(format!("RFC本文に禁止表現 '{word}' が含まれています"));
            }
        }

        // 条件4: Δ = 0
        if delta > 0.0 {
            errors.add(format!("Δ = {} > 0。乖離が残っています", delta));
        }

        // 条件6: STUB ゼロ
        if stub_count > 0 {
            errors.add(format!(
                "未解決 STUB が {} 件あります",
                stub_count
            ));
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }
}

#### 2.6 DagValidator（petgraph DAG検証）

RFCツリーとチケットDAGの構造検証。

```rust
// conver-validation/src/dag.rs
use crate::{Validator, ValidationErrors};
use petgraph::graph::DiGraph;
use petgraph::algo::is_cyclic_digraph;

/// DAG検証ゲート。
///
/// 検証対象:
/// - RFC_TREE.json（RFCツリーDAG）
/// - Tickets.json（チケットDAG）
///
/// 検証ルール（RFCツリー）:
/// - ノードIDの一意性
/// - 依存辺のみ循環検出（階層辺はツリー構造で自己無矛盾）
/// - 親→子の依存辺の禁止（意味的矛盾）
///
/// 検証ルール（チケット）:
/// - チケットIDの一意性
/// - 依存先チケットIDの実在性
/// - RFC境界を跨ぐ依存の正当性
/// - 有向閉路の不存在
pub struct DagValidator;

impl DagValidator {
    pub fn new() -> Self {
        Self
    }

    /// RFCツリーDAGを検証する。
    pub fn validate_rfc_tree(&self, json: &str) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        // JSONパース
        let tree: serde_json::Value = serde_json::from_str(json)
            .map_err(|e| ValidationErrors::from(vec![format!("RFC_TREE.json パースエラー: {e}")]))?;

        let nodes = tree.get("nodes").and_then(|v| v.as_array())
            .ok_or_else(|| ValidationErrors::from(vec!["nodes 配列が必要".to_string()]))?;

        // ID一意性
        let mut ids = std::collections::HashSet::new();
        for node in nodes {
            let id = node.get("id").and_then(|v| v.as_str())
                .ok_or_else(|| ValidationErrors::from(vec!["各ノードに id が必要".to_string()]))?;
            if !ids.insert(id) {
                errors.add(format!("重複ID: {id}"));
            }
        }

        if !errors.is_empty() {
            return Err(errors);
        }

        // petgraph で依存辺のみのDAG検証
        let mut graph = DiGraph::<(), ()>::new();
        let indices: std::collections::HashMap<&str, _> = ids.iter()
            .map(|id| (*id, graph.add_node(())))
            .collect();

        for node in nodes {
            let id = node["id"].as_str().unwrap();
            if let Some(deps) = node["depends_on"].as_array() {
                for dep in deps {
                    if let Some(dep_id) = dep.as_str() {
                        if let Some(&from) = indices.get(dep_id) {
                            if let Some(&to) = indices.get(id) {
                                // 親→子の依存チェック
                                if let Some(children) = node["children"].as_array() {
                                    if children.iter().any(|c| c.as_str() == Some(dep_id)) {
                                        errors.add(format!(
                                            "親→子依存違反: {id} は子 {dep_id} に依存できません"
                                        ));
                                    }
                                }
                                graph.add_edge(from, to, ());
                            }
                        }
                    }
                }
            }
        }

        if is_cyclic_digraph(&graph) {
            errors.add("RFCツリーDAGに循環が検出されました");
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }

    /// チケットDAGを検証する。
    pub fn validate_ticket_dag(&self, json: &str) -> Result<(), ValidationErrors> {
        let mut errors = ValidationErrors::new();

        let data: serde_json::Value = serde_json::from_str(json)
            .map_err(|e| ValidationErrors::from(vec![format!("Tickets.json パースエラー: {e}")]))?;

        let tickets = data.get("tickets").and_then(|v| v.as_array())
            .ok_or_else(|| ValidationErrors::from(vec!["tickets 配列が必要".to_string()]))?;

        let mut ids = std::collections::HashSet::new();
        for ticket in tickets {
            let id = ticket.get("id").and_then(|v| v.as_str())
                .ok_or_else(|| ValidationErrors::from(vec!["各チケットに id が必要".to_string()]))?;
            if !ids.insert(id) {
                errors.add(format!("重複チケットID: {id}"));
            }
        }

        // 依存先の実在性チェック
        for ticket in tickets {
            let id = ticket["id"].as_str().unwrap();
            if let Some(deps) = ticket["depends_on"].as_array() {
                for dep in deps {
                    if let Some(dep_id) = dep.as_str() {
                        if !ids.contains(dep_id) {
                            errors.add(format!(
                                "チケット {id}: 依存先 {dep_id} が存在しません"
                            ));
                        }
                    }
                }
            }
        }

        if errors.is_empty() { Ok(()) } else { Err(errors) }
    }

    /// DAG検証の構造化結果を返す。
    pub fn validate_with_report(&self, json: &str) -> DagValidationReport {
        let result = self.validate_rfc_tree(json);
        DagValidationReport {
            valid: result.is_ok(),
            errors: result.err().map(|e| e.errors).unwrap_or_default(),
        }
    }
}

/// DAG検証結果レポート。
#[derive(Debug, Clone)]
pub struct DagValidationReport {
    pub valid: bool,
    pub errors: Vec<String>,
}

    fn validation_errors_merge() {

### E. 設計資料（crates/conver/docs/）の利活用

`crates/conver/docs/` ディレクトリには本RFCおよび全子RFCの設計に先立って
収集・生成された設計資料が格納されている。これらの資料は以下のように利活用する。

#### 構成

| パス | 内容 | 本RFCとの関係 |
|------|------|-------------|
| `docs/conver-rfc-design-ja.md` | オリジナルRFC草案 | 本RFCの前身。grillセッションのインプットとして使用された |
| `docs/rfc_tree_self_converging_development_design.md` | 完全版設計記述 | 自己収束開発サイクルの理論的背景。数学的定式化の原典 |
| `docs/EVALUATION.md` | 専門家による設計評価 | 本RFCで解決された6つの指摘を含む評価レポート |
| `docs/claude/commands/*.md` | 7種のスラッシュコマンド定義 | `conver init` で配布されるコマンドの参考実装。互換性検証に使用 |
| `docs/claude/scripts/grill-me-for-rfc/*.js` | 9種のgrill用スクリプト | conver-cli の各機能のリファレンス実装。Rust移植の検証用 |
| `docs/claude/scripts/tickets/*.js` | 17種のチケット管理スクリプト | conver-core のチケット操作のリファレンス実装 |
| `docs/claude/scripts/tickets/review/*.js` | 3種のレビュー・品質スクリプト | conver-validation の品質ゲートのリファレンス実装 |
| `docs/claude/scripts/lib/*.js` | 4種の共通ライブラリ | 各crateの共通ロジックの参考実装 |

#### 利活用方法

1. **互換性検証**: `cargo run --bin test-run` の出力と従来スクリプトの実行結果を
   比較することで、Rust移植の正しさを機械的に検証できる。
2. **リファレンス実装**: 各Node.jsスクリプトは対応するRustモジュールの
   リファレンス実装として機能する。仕様の曖昧な部分は従来スクリプトの
   動作を確認することで補完できる。
3. **回帰テスト**: 従来スクリプトのテストケースをRustのテストコードとして
   再利用することで、機能退行を防止する。
4. **ドキュメント原典**: `docs/rfc_tree_self_converging_development_design.md` は
   数学的定式化の原典であり、RFC_006の理論的根拠として参照する。

    ▼
[Gate 4] 品質ゲート (QualityGate) - 最終完了時のみ

    ▼
    操作確定 + チェックポイント commit
```
