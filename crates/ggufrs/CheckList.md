## AI補足: プロジェクト固有の制約・注意事項

### 言語と記述ルール
- [ ] RFC は日本語で記述する（設計書は日本語、コードコメントも日本語）
- [ ] コードスニペット内の `log::info!` 等の実行ログは英語で記述する（言語プロトコル準拠）
- [ ] Everything as Code: コードとコメントは一体。意図・制約・背景を説明するコメントを付与
- [ ] 可読性とは翻訳可能性: 関数名・変数名で処理内容が自然言語に逐語訳できること

### 実装制約
- [ ] mistralrs は**今日時点の最新版**を使用する（バージョン固定しない）
- [ ] `default-features = false` + `features = ["gguf"]` を基本としつつ、GPU feature は cargo feature で分離
- [ ] モデル初期化の重複禁止: 同一 GgufEngine 内でモデルは必ず共有され、再初期化されない設計であること
- [ ] settings.rs は静的定数のみ（ポート番号・デフォルトパス等）。モデル設定は JSON config
- [ ] JSON config の3層マージ優先順位: ファイルパス > include_str! 埋め込み > コードベタ書き
- [ ] GPU自動検出のデフォルト: macOS=Metal, Windows=DirectML, Linux=CPU（CUDAは別feature）

### モデル管理
- [ ] build.rs のダウンロード元URLを明記（unsloth/Qwen3.5-0.8B-GGUF, unsloth/Qwen3.5-2B-GGUF）
- [ ] モデルファイルは tokenizer を GGUF 内に自己内包するため別途 tokenizer ファイル不要
- [ ] models/ は .gitignore に追加（voiput準拠）
- [ ] curl のタイムアウトは60秒（voiput準拠）、ダウンロード失敗時は不完全ファイルを削除

### アーキテクチャ
- [ ] GgufEngine 統合型: 単一構造体 + Arc\<Model\> 共有 + RwLock\<Vec\<ModelInfo\>\> Registry
- [ ] ServerConfig.auto_start_server: false なら純粋ライブラリモード、true なら new() 時に自動起動
- [ ] JoinHandle\<Result\<()\>\> 返却方式でサーバー死活監視・abort・終了待機を可能に
- [ ] start_server() は明示的呼び出しも可能（auto_start_server とは独立した2経路）

### InferenceEngine トレイト
- [ ] 高レベル3メソッド: generate / generate_structured / generate_stream
- [ ] 低レベル委譲: send_raw(model_name, RequestBuilder) で mistralrs 全機能アクセス
- [ ] トレイトが mistralrs より劣る機能セットになっていないことを検証する
- [ ] 各メソッドは model_name: &str を受け取り推論単位でのモデル切替を実現

### GgufError 6バリアント
- [ ] ModelNotFound / ModelLoadFailed / InferenceFailed / ServerStartupFailed / InvalidConfig / MistralrsError(Box\<dyn Error\>)
- [ ] 各バリアントに From トレイト実装で ? 演算子による伝搬を可能にする

### テスト
- [ ] 単体テストは InferenceEngine トレイトのモック実装で行う（実モデル不要）
- [ ] 結合テストは tests/ ディレクトリで build.rs ダウンロード済み実モデルを使用
- [ ] スタブ禁止: 全てのテストは実際に実行可能であること
- [ ] cargo run --bin test-run で Structured Output → 通常生成 → ストリーミング の全パターンを順次実行
