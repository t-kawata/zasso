## 13. Per-Project Completion Criteria

| Project | Completion |
|---|---|
| <project-c> | All seven existing roles mapped; identity crates added; catalog complete; conformance matrix covers REST/WS/CLI/gRPC; MCP/A2A declared absent. |
| <project-a> | Core split resolved; identity crates added; REST/WS/CLI pass conformance; gRPC/MCP/A2A declared absent. |
| <project-b> | Identity crates added; REST created; catalog and conformance pass; remaining interfaces declared absent. |

A project is not complete because it compiles. It is complete when the
conformance report has no `Fail` and no missing rule.
