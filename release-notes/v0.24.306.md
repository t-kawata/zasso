# Release v0.24.306

## Summary
Fixes for OpenAI STT pipeline: SttCompleted emission on PartialResult and SpeechEnd, GTCRN denoiser model path configuration, VAD stuck recovery via intelligent timeout, and --no-denoiser CLI flag for testing.

## What's Changed
- **fix**: Restore SttCompleted emission after non-decorating PartialResult (mycute compatibility)
- **fix**: Emit SttCompleted on SpeechEnd buffered PartialResult flush to release is_stt_pending
- **fix**: GTCRN denoiser model path now correctly set to models/gtcrn.onnx
- **feat**: Remove 25-second `time_exceeded` requirement from intelligent timeout; VAD stuck recovery triggers on ASR stagnation (3s) + low signal
- **feat**: Add `asr_stagnation_threshold_secs` field to VadConfig and StreamerConfig (default 3.0s)
- **feat**: Add `--no-denoiser` CLI flag to disable GTCRN denoiser for testing
- **chore**: Tickets #85, #86, #87 — spec, implementation, review artifacts
