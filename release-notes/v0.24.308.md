# Release v0.24.308

## Summary
OrchestratorInput (Ctrl+Option) now auto-starts recording, emits Flushed event with commit sound, and properly tracks pending flush origin to avoid incorrect clipboard paste.

## What's Changed
- **feat**: OrchestratorInput auto-starts recording when not recording (Ctrl+Option in idle state)
- **feat**: OrchestratorInput now plays commit_sound on flush (both BufferFlush and OrchestratorInput)
- **feat**: Add `pending_flush_is_orchestrator` flag to distinguish pending flush source, fixing deferred flush target (clipboard vs Flushed event)
- **feat**: Flushed event emitted with proper sound even when text is empty
- **fix**: `--no-denoiser` CLI flag now properly wired to builder (was declared but never read)
- **chore**: Tickets #88, #89 — OrchestratorInput refactoring and pending flush fix
