# Release v0.24.315

## Summary

Implemented the M1 milestone of the trate crate: `AsrBackend` and `LocalAsrBackend` trait definitions with 7 unit tests, completing the trait abstraction layer for pluggable speech recognition backends.

## What's Changed

- **feat: add `AsrBackend` trait to trate crate** — core trait with `transcribe()` as the only required method and default implementations for `post_correct()`, `backend_name()`, `record_asr_usage()`, and `insert_punctuation()`. Includes `Send` supertrait and `pub mod local` declaration
- **feat: add `LocalAsrBackend` trait** — extends `AsrBackend` with `model_path()` and `is_healthy()` for local ASR backends (Qwen3-ASR, future Whisper/SenseVoice)
- **test: add 7 mock-based unit tests to trate** — covering empty/non-empty transcribe, default backend_name, post_correct passthrough, insert_punctuation passthrough, model_path, and is_healthy
- **docs: update Tickets.md with completion markers** — M1-1 and M1-2 marked as completed
