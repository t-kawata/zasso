# Release v0.24.316

## Summary

Completed the M2 milestone of the voiput type system extension: added `LocalAsrKind`, `SttEngine::Local`, `Qwen3AsrModelPaths`, and `Qwen3AsrConfig` types, plus VoiputConfig integration. Added temporary match stubs for `SttEngine::Local` to maintain compilation (resolved in M6-1).

## What's Changed

- **feat: add `LocalAsrKind` enum** — new enum with `Qwen3Asr` variant for local ASR backend type dispatch
- **feat: add `SttEngine::Local` variant** — third engine variant with `{ backend: LocalAsrKind }` data, includes `[::STUB::]` match arms at 4 sites for intermediate compilation (resolved in M6-1)
- **feat: add `Qwen3AsrModelPaths` and `Qwen3AsrConfig` structs** — model file path container (encoder/decoder/joiner/tokens) and inference parameter struct, integrated into `VoiputConfig` and `VoiputConfigBuilder`
- **docs: update Tickets.md** — added completion markers for M2-1/M2-2/M2-3, documented 4 stub locations in M6-1
- **tickets: complete M2-1, M2-2, M2-3** — all three tickets completed and reviewed
