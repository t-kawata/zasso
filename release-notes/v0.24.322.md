# Release v0.24.322

## Summary

Completed the M4 milestone: implemented the Qwen3-ASR local speech recognition backend using sherpa-onnx's OfflineRecognizer, with AsrBackend and LocalAsrBackend trait implementations.

## What's Changed

- **feat: add Qwen3AsrBackend (M4-2)** — new struct wrapping `Mutex<OfflineRecognizer>` with `new()` and `transcribe()` methods implementing the `AsrBackend` trait. Includes model file path configuration via `Qwen3AsrConfig`
- **feat: add LocalAsrBackend impl for Qwen3AsrBackend (M4-3)** — implements `model_path()` and `is_healthy()`, plus `validate_qwen3_model_files()` for pre-flight model file existence checks
- **feat: create voiput local module (M4-1)** — directory structure with `mod.rs`, `qwen3.rs`, and `recognizer.rs` for Qwen3-ASR related code
- **fix: remove lock().unwrap() in production code** — replaced with `map_err` for proper error propagation
- **fix: update M2-5 stub resolution ticket references** — corrected `[::STUB::]` markers from M4-2 to M5-1 for path resolution functions
- **test: add 4 unit tests for M4-3** — covering model_path, is_healthy, validate all files, validate missing file
- **tickets: complete M4-1, M4-2, M4-3** — all three tickets completed and reviewed
