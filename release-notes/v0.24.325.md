# Release v0.24.325

## Summary

Implemented Qwen3-ASR local speech recognition backend with PseudoAsrStreamer pipeline integration, test-run --engine local support, and a full integration test. Fixed recognizing pipeline regression and model file download URLs.

## What's Changed

- **feat**: Add `--engine local` support to test-run binary and `run-local`/`run-local-no-denoiser` Makefile targets
- **feat**: Add Qwen3-ASR integration test (`qwen3_asr_test.rs`) with real model and sample voice recognition
- **feat**: Implement PseudoAsrStreamer audio capture pipeline in LocalRecognizerAdapter (mic → VAD → Qwen3-ASR)
- **fix**: Correct Qwen3-ASR model file URLs (replace joiner.int8.onnx/tokens.txt with conv_frontend.onnx/tokenizer/)
- **fix**: Fix LocalRecognizerAdapter event relay regression — move event polling into background thread, use Arc<Mutex> for streamer_rx
- **fix**: Prevent Qwen3-ASR model reloading across start/stop cycles by keeping streamer alive
- **refactor**: Share `build_streamer_config()` between OpenAI and Local backends
- **chore**: Update `Qwen3AsrModelPaths` struct fields to match actual model structure
- **test**: Add recognition timing display to Qwen3-ASR integration test
