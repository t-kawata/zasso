# Release v0.24.326

## Summary

Completed full feature parity between OpenAI and Local (Qwen3-ASR) speech recognition backends. Added decoration animation, SttPending/SttCompleted events, post-correction backend injection, and aligned post-correction prompts with mycute.

## What's Changed

- **feat**: Add decoration animation (" ... " / "? " cycling) to LocalRecognizerAdapter
- **feat**: Add SttPending / SttCompleted / ForceClearDecoration event support to Local backend
- **feat**: Inject post-correction backend into PseudoAsrStreamer — Local engine now uses OpenAI API for post-correction when --openai-key is provided
- **feat**: Align post-correction prompts with mycute (JA/EN locale switching, ASR-aware instructions, noise removal rules)
- **feat**: Add strip_result_tags() to handle <result>-tagged LLM responses
- **feat**: Auto-tune CPU thread count to half of system cores for ASR and VAD
- **fix**: Trim trailing whitespace from commit_correction() output
- **fix**: Remove hardcoded num_threads=4, replace with auto_num_threads()
- **refactor**: PseudoAsrStreamer::new() now accepts optional post_correct_backend parameter
- **refactor**: Decoration timeout now reads vad.max_speech_duration dynamically
