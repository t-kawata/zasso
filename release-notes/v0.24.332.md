# Release v0.24.332

## Summary
Implemented M0 milestone — Layer 0 type definitions for the ggufrs crate, a Rust GGUF model inference engine built on mistralrs. Added 10 source files with 46 unit tests covering all foundational types.

## What's Changed
- **feat(ggufrs)**: Create ggufrs crate skeleton (Cargo.toml, lib.rs, .gitignore, Makefile integration)
- **feat(ggufrs)**: Add static constants (ports, model dir, timeouts, inference defaults)
- **feat(ggufrs)**: Define GpuProvider enum (Auto/Metal/DirectML/Cuda/Cpu) with serde support
- **feat(ggufrs)**: Define GgufError enum (6 variants) with thiserror and mistralrs error conversion
- **feat(ggufrs)**: Define config structs (ModelConfig, ServerConfig, GgufConfig, ConfigLayer)
- **feat(ggufrs)**: Define ModelInfo struct with From<ModelConfig> conversion
- **test(ggufrs)**: Add 46 unit tests covering all type definitions, JSON roundtrips, Display/Source traits
- **chore(Makefile)**: Add `make check-ggufrs` target for crate-level build verification
