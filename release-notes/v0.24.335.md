# Release v0.24.335

## Summary
Completed M1 Layer 1 (pure functions) and M2 Layer 2 (async runtime) for the ggufrs crate. Added 8 source file changes with 57 new unit tests (103 total).

- **feat(ggufrs)**: Add GgufError From implementations for std::io::Error and serde_json::Error (M1-3)
- **feat(ggufrs)**: Implement GgufConfig merge_overlay with name-based model merging + conditional server/gpu override (M1-4)
- **feat(ggufrs)**: Add ModelRegistry synchronous API (new, from_config, add_model, list_models) (M1-5)
- **feat(ggufrs)**: Define InferenceEngine trait with 4 async methods + GenerateParams (M2-1)
- **feat(ggufrs)**: Add ModelRegistry async methods (get, load_immediate, load_all) (M2-2)
- **feat(ggufrs)**: Implement GgufEngine entry point with new() constructor (M2-3)
- **test(ggufrs)**: Add mockall-based unit tests (MockEngine, 8 mock tests) (M2-4)
- **chore**: Add mockall v0.14.0 dev-dependency
- **fix**: Resolve env var race condition in detect() tests, fix async_trait lifetime issues in mock tests
