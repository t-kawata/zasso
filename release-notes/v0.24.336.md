# Release v0.24.336

## Summary

Complete the M3 milestone for ggufrs — the GGUF model inference engine crate. All four InferenceEngine methods (generate, generate_structured, generate_stream, send_raw) are now implemented, along with GgufConfig 3-layer merge support, GgufModelBuilder model loading, and comprehensive test coverage.

## What's Changed

### ggufrs — M3 Milestone Complete (5 tickets)

- **feat**: Implement GgufConfig::build + 3-layer merge (M3-1) — code > embedded JSON > file JSON merge with full error handling
- **feat**: Implement generate() / generate_structured() (M3-2) — model resolution via GgufModelBuilder, GenerateParams→SamplingParams conversion
- **feat**: Implement generate_stream() (M3-3) — channel-based streaming with mistralrs Stream API, raw pointer lifetime management
- **feat**: Implement send_raw() (M3-4) — RequestBuilder passthrough to mistralrs
- **feat**: Complete lib.rs public API re-export (M3-5) — all ggufrs and key mistralrs types accessible via `use ggufrs::*`
- **fix**: Update settings.rs STUB comment to reflect current usage status

### Tests

- 136 passing tests (up from 52 at M0 baseline)
- Full coverage for config merge, params conversion, stream response handling
