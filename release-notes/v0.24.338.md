# Release v0.24.338

## Summary
ggufrs M5 milestone initial phase: model auto-download, test-run binary, and GgufModelBuilder directory path fix. Added Gemma4 E2B/E4B documentation and planned the Gemma4 migration with performance optimization strategies.

## What's Changed
- **feat: build.rs model auto-download (M5-1)**
  - Automatic download of Qwen3.5-0.8B-Q4_K_M and Qwen3.5-2B-Q4_K_M models via curl/powershell
  - Idempotent download (skips existing files), timeout at 60s
  - `cargo:rerun-if-changed=models/` for incremental builds

- **feat: test-run binary (M5-2)**
  - 3-pattern inference verifier: Structured Output, Text Generation, Streaming
  - Separator-labeled output with PASS/FAIL summary
  - Error-tolerant: each pattern fails independently without crashing

- **fix: GgufModelBuilder directory path resolution**
  - `model_path` was passed as a file path, but `GgufModelBuilder::new()` expects a directory
  - Fixed by extracting parent directory and filename as glob pattern

- **docs: Gemma4 E2B/E4B migration plan**
  - Added detailed guide and performance estimates (INFO.md)
  - Planned M5-2.x subtickets with context_size=2048, thinking OFF, max_tokens optimization
  - Estimated latency: E2B ~300ms, E4B ~800ms per correction round

- **fix: .gitignore `src/bin/` exclusion**
  - Root `.gitignore` had `**/bin/` pattern that ignored test-run.rs
  - Added negation rule in crate-level `.gitignore`
