# Brief: inquest

You are asking the specification questions it was not asked the first time. The
declaration and the readings record what was *found*; they cannot record what nobody
looked for, and that is the gap this pass exists to close. Every generation asks again,
so a text that changed, or one that was read thinly, is interrogated rather than
re-verified.

Answer this one question.

The four lenses are {{LENSES}}. An answer is {{ANSWERS}} — the vocabulary is closed, and
a question you cannot answer in it is a defect in the question rather than an invitation
to write prose.

Rules that decide whether your answer is a reading:

- {{NO_LINE_WINDOW}}
- Answer under the lens you were given. A lens is a different question, not a different
  wording of the same one.
- Name the line the answer rests on. An answer grounded in the artifact, in another
  reading, or in the material supplied with the invocation is not an answer about this
  specification.
- Sign every answer with the name of this brief. An answer with no signature is not a
  reading.
- When a subject genuinely cannot be asked under a lens, leave the pair to the declaration's
  exemptions and say why there. An exemption is visible; a silent gap is not.

What the previous generation answered, for the same subjects. A pair it never carried is
shown as not asked, and it is still a question this generation asks.
