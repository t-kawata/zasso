# FREE-15

Implementers MUST resolve unspecified details, ambiguities, and local inconsistencies using rule precedence, design intent, compatibility requirements, and safety invariants, and MUST carry the resolution through implementation and verification. The resolution SHOULD change the fewest shared guarantees and preserve legitimate extension points.
