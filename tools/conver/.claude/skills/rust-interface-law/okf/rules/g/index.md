- [OPS-13 — Operation inputs and outputs MUST be protocol-independent. Protobuf-generated types, HTTP types, and CLI types MUST NOT appear in `*-operation`.](./ops-13.md)
- [OPS-18 — The generated `ContractValidate::validate()` MUST run in the common dispatch path for every interface, before idempotency claim and business logic.](./ops-18.md)
- [VAL-12 — The generated validator runs after typed conversion and before the idempotency claim; prepare runs only on the acquired branch.](./val-12.md)
- [VAL-16 — Hand-written constraint lists are forbidden; documentation is generated from descriptors.](./val-16.md)
- [VAL-19 — Validation descriptors and generated documentation contain no secrets or sensitive examples.](./val-19.md)
- [VAL-20 — Generation is deterministic for the same descriptor set and version.](./val-20.md)
