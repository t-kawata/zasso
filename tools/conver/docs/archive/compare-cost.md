


# A. 従来の開発方法 / B. Claude Fable 5 / C. Night-Imp-Loop 開発コスト比較

## ⚫︎ ABC 共通の条件
```
- 月給80万円（コスト100万円）のエンジニア１人とする
- その人は、かなり仕事が速く、正確であるとする
- 最終チケット件数は、Night-Imp-Loop の結果に合わせて 32チケット とする
- Claude Fable 5 と Night-Imp-Loop の仕事の速さは同じとする
- Night-Imp-Loop と Claude Fable 5 は、1チケット15分とする
- 開発における「1周」だけを計算する（通常、最低数回転はしないと完成しない）
```

## ⚫︎ まずは結論

**AINativeソフトフォンの「開発1周目」に、ABCそれぞれいくらかかるのか**

| 開発方法 | かかる時間 | コスト | コスト倍率 |
| --- | ---: | ---: | ---: |
| 🔴 A. 従来の開発方法 | 65日（3.25ヶ月） | 325万円 | 29.5倍 |
| 🟡 B. Claude Fable 5 | 2.2日 | 24万円 | 2.2倍 |
| 🔵 C. Night-Imp-Loop | 2.2日 | 11万円 | -- |

## ⚫︎ 開発作業は以下の順とする
```
①. RFC型の設計書を書き上げる
②. 設計書を安全な I/O 境界に区切って詳細設計を書き上げる
③. 詳細設計の I/O 境界をディレクトリとファイルに分解する
④. 実装の最小単位であるチケットに細分解する
⑤. チケットを全て実装し、テストする
⑥. 上記1のRFC型設計書に対して 危険・漏れ・矛盾・不足 が無いことを確認する
```
