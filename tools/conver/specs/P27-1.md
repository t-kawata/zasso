# P27-1: find-omissions proves a previous run did not finish and resumes it mechanically

## Goal

`/find-omissions` reads package-local artifacts and decides, deterministically, that a previous run of itself stopped before Step 9 completed. On that verdict it enters RESUME mode, clears only its transient queues, and finishes without asking a human.

## Purpose

`remanded`, an `IN_PROGRESS` boundary record, and leftover `_tmp-*` files are the only traces an interrupted run leaves. Without one mechanical reader, an operator cannot tell an unfinished run from a complete one, and a stale `remanded` blocks every later loop.

## Motivation

`crystal-adapter-observer` P0-1 was `remanded` while six tickets were `reviewed`, the package held no omission artifacts and `round=1`, and conver's find history ended `BLOCKED_PREREQUISITE`. That is an unfinished run, but only a script reading the artifacts can prove it.

## Constraints

- Generic: only conventional package artifacts; no workspace or package names.
- Deterministic: same tree, same verdict and evidence.
- Read-only by default; `--reset` removes only transient `_tmp-*` files.
- Default output is Markdown; JSON is opt-in for a machine consumer.
- Incompleteness never becomes a question for the human.

## Scope

- Add `.claude/scripts/tickets/detect-unfinished-find.js`.
- Update `.claude/commands/find-omissions.md` pre-flight and resume procedure.
- Update `.claude/scripts/tickets/validate-graph-arg.js` to read the first non-empty line.

## Contracts → testable form

| Contract | Input schema | Output assertion | Invariant predicate |
|---|---|---|---|
| C001 clean verdict | package with terminal tickets, no find-in-progress, no `_tmp-*` | exit 0, `unfinished=false`, `evidence=[]` | verdict independent of names |
| C002 evidence classes | a `remanded` ticket outside PX / boundary `find.status=IN_PROGRESS` / `_tmp` queue / `_tmp` omissions | exit 10 and each class named | PX phase excluded |
| C003 argument parse | one argument whose first non-empty line is a readable graph path | exit 0 and the path resolved; directive ignored | no graph line → exit 2 |

## Acceptance criteria

- Clean tree exits 0 in both Markdown and JSON.
- Each evidence class alone yields exit 10.
- `_tmp` presence alone is unfinished even when every queue entry is `done:true`.
- `--reset` removes named transient files and leaves Tickets.json and `.conver-boundary.json` byte-identical.
- Malformed tickets or boundary exits 20, never 10.
- Multi-line `<graph>\n\n<directive>` validates the graph.
- Fixtures use neutral names only.

## Invariants

- A parse failure is never evidence of incompleteness.
- Reset never edits durable state.
- The PX phase is never inspection evidence.
