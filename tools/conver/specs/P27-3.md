# P27-3: The find pre-flight is one script that prints one verdict

## Goal

`/find-omissions` calls one shell script with the raw `$ARGUMENTS`. The script runs every gate, resets transient files only after every read-only gate passes, and prints one line per gate plus one final verdict.

## Purpose

Control flow embedded in prose is re-derived by the AI on every run and is easy to get wrong. A script makes the order, exit codes and reset decision deterministic, and its output shows what each gate decided.

## Motivation

The previous block ran the unfinished-find detector and its reset before the consolidated-manifest gate, so a package blocked by an unconsolidated stub tree lost the omissions recorded by its interrupted run. The block was also copied by hand; a `|| exit 2` applied to an exit-10 detector would turn a resume into a block.

## Constraints

- One positional argument: the raw `$ARGUMENTS` (graph on the first non-empty line, optional directive after a blank line).
- No `eval`; the argument is passed quoted to each node gate.
- Read-only gates first; reset last.
- Exit 0 = continue; exit 2 = stop. No exit 10 leaks to the caller.
- Output English, one line per gate, evidence and removed files included.
- Resolve gates from the script's own location; work from any package directory.

## Scope

- Add `.claude/scripts/tickets/find-omissions-preflight.sh`.
- Replace the command's Gate block with one invocation.
- Add `tests/find-omissions-preflight.test.cjs`; update the doc test.

## Contracts → testable form

| Contract | Input | Output | Invariant |
|---|---|---|---|
| C001 | one raw argument; cwd is a package dir | exit 0 + `MODE: CLEAN` / `MODE: RESUME`, or exit 2 + `VERDICT: STOP`; one line per gate | no transient file removed before every read-only gate passes |
| C002 | the command document | exactly one `bash ...-preflight.sh "$ARGUMENTS" \|\| exit 2` line | the script, not prose, owns order and reset timing |

## Acceptance criteria

- Clean package: exit 0, `MODE: CLEAN`, graph/unfinished/manifest lines, `VERDICT: CONTINUE`.
- Unfinished package: exit 0, `MODE: RESUME`, detector evidence, reset list, files removed.
- Invalid graph: exit 2, no reset.
- Stubs without a manifest: exit 2 and no reset (ordering proof).
- Malformed Tickets.json: exit 2, no reset.
- Multi-line graph + directive: exit 0, CLEAN.
- The script has a bash shebang and contains no `eval`.

## Test plan

`tests/find-omissions-preflight.test.cjs` covers all seven cases above. `tests/find-omissions-doc.test.cjs` asserts the single invocation and the MODE vocabulary.
